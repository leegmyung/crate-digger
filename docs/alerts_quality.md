## 4. 고친 점 (`scripts/build_alerts.py`, 테스트 먼저 — `tests/test_build_alerts.py` 31개)

| 원인 | 고친 규칙 |
|---|---|
| 늦게 수집·다시 적재·연결표 변경으로 지문이 바뀐 **옛 기록** | 새로 본 신호라도 날짜가 기준일 30일보다 옛날이면 '오늘 일'로 안 침(`is_fresh`). 단계 상승·백지 신인·언급 급증·큰 공연장·같은 무대 수상 팀·순위 급상승은 최근(또는 다가오는) 새 신호만 씀 |
| **새 신호 없이** 재계산으로 바뀐 단계 | 단계 상승은 그 팀에 최근 새 '남의 언급'이 있을 때만 |
| **새 팀 첫 신호 1건** 몰림 | 지난번 후보 목록에 없던 팀은 첫 기록이 최근인 진짜 새 팀이면서 2단계(여러 갈래) 이상일 때만 '새로 나타난 팀' |
| **후보군 변화**(신인 판정·연결표) | 위 규칙으로 함께 빠짐(옛 기록이 있으면 새 팀이 아님) |
| 수상 팀 쪽 변화로 생긴 **옛 무대 연결** | 같은 무대 수상 팀은 최근 무대이면서 그 팀 쪽 공연이 새로 본 최근 공연일 때만 |
| 새 신호 없는 **순위 변화** | 순위 급상승은 최근 새 신호가 있는 팀만 |
| 옛 큰 공연장 기록이 새 지문이 된 경우 | 옛 날짜 공연은 새로 본 것이라도 '이미 섰음'으로 침 |
| **몇 달 전 선정**이 오늘 적재 | 지우지 않고 `late: true`, 설명에 '(늦게 확인 — 날짜 일)', 중요도 −30 |
| **미래 날짜**가 정렬 맨 위 | 정렬할 때 미래 날짜는 기준일로 침 |
| **같은 팀 여러 종류** | `also`(상한 전 찾은 알림 기준)로 다른 종류를 붙임 |
