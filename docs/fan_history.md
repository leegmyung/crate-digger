# 멜론 팬 수 기록 (요약)

_자동 생성: `.venv/bin/python scripts/fan_history.py` · 원본 기록은 `data/raw/state/fan_history.json`(비공개, 커밋 안 함)_

**왜 쌓나**: 유명 팀 제외는 '지금' 팬 수로 정해져서, 과거 기준일 검증에는 쓰지 않는다([규칙 시점 점검](rule_leakage.md)). 팬 수를 날짜별로 쌓아 두면 나중에 '기준일 당시 알던 팬 수'로 유명 판정을 할 수 있다(그때 `fame_known_from()`을 기록 시작일로 둔다).

| 항목 | 값 |
|---|---|
| 팬 수 기록이 있는 아티스트 | 309 |
| 기록 날짜 | 2일 (2026-11-26 ~ 2026-11-27) |
| 두 날짜 이상 기록된 아티스트 (변화를 볼 수 있음) | 0 |
| 최근 팬 수 사분위 (25%·중앙값·75%) | 65 · 283 · 1,745 |
| 팬 1만 이상 / 1천 이상 | 36 / 105 |

**지금 한계**: 멜론 수집기(`collect_artists.py`)는 한 번 받은 아티스트를 다시 받지 않는다(`artist_profile_seen.json`). 그래서 같은 아티스트의 팬 수가 날짜별로 쌓이려면 **관찰 목록(후보 상위·정답 팀)을 주기적으로 다시 받는 모드**가 필요하다. 지금은 두 날짜 이상 기록된 아티스트가 없다.
