야구 기록 사이트처럼 숫자를 촘촘하게. 점수 근거를 항목마다 0~100 백분위 막대로 보여 줍니다.

잘 맞는 때: "왜 이 팀이 위인가"를 숫자로 바로 확인하고 싶을 때.
