> **어떻게:** 인스타는 aside 브라우저로 프로필을 열어 이름·소개를 읽고(로그인 없이, `collect_ig_artists` 와 같은 읽기), 유튜브는 YouTube Data API `channels.list`(1단위씩, 32단위)로 채널 제목·핸들·설명, 스포티파이는 공개 아티스트 페이지(robots 허용 `/artist/`)의 이름. 표본은 고정 씨앗(20261128)으로 무작위.

## 3. 점검하다 찾은 것

1. **인스타 수집기의 '아티스트 아님' 오판 (고침).** `collect_ig_artists.looks_non_artist` 가 이름·소개 어디든 club·label·live 같은 말이 있으면 아티스트 아님으로 봐서, 투파이브(소개에 'Punk Rock Band … Label - @…')와 줄라이원츠모어(소개의 공연 일정 '12/04 금 Club FF')가 아티스트 아님으로 갈렸다.
   **새 규칙(테스트 먼저, +4):** 이름에 그런 말이 있으면 그대로 아티스트 아님 / 소개는 공연 일정 줄(`12/04 …`)을 빼고 본다 / 공연장·카페·펍·음악 레이블·매거진·페스티벌 소개는 아티스트 낱말이 있어도 아티스트 아님 / 그 밖엔 소개에 밴드·싱어송라이터·래퍼·록·펑크 같은 아티스트 낱말이 있으면 아티스트.
   기존 판정에 적용하면: '아티스트 아님' 12개 중 3개(雪国·우륵과 풍각쟁이들·줄라이원츠모어 — 모두 실제 밴드)가 아티스트로, 기존 아티스트 중 바뀌는 계정 0.
2. **스포티파이 `/v1/artists?ids=` 가 403** (개발자 모드 제한). 월요일 `followers_spotify_weekly.py` 는 요청 1번 뒤 '오류: HTTP 403'으로 멈추고 그 주를 끝낸다(해는 없지만 쓸모도 없음). 대신 **공개 아티스트 페이지(robots 허용 `/artist/`)에 '월간 청취자'** 가 나온다(예: 'Artist · 92.5K monthly listeners') — Chartmetric 이 쓰는 지표와 같다. 제안: 주 1회 단계를 공개 페이지에서 월간 청취자를 읽는 방식으로 바꾸기(관찰 팀 중 스포티파이 번호가 있는 팀, 한 번에 한 페이지).
3. **유튜브 'Topic' 채널.** 채널 검색이 고른 채널 중 'Topic'(유튜브 자동 생성)은 같은 이름 다른 사람의 음원일 수 있다 → `yt_channel_search` 에서 제목이 ' - Topic' 으로 끝나는 채널은 자동 연결하지 않기 제안(그 파일은 다른 작업자 담당이라 제안만). 팀이 직접 적은 sameAs 의 Topic 채널은 그대로.

## 4. 차단 목록 방식 제안 (config 파일)

틀린 연결이 나오면 원본 수집 결과를 고치지 않고 **차단 목록**으로 막는다.

```json
// config/link_blocklist.json
{
  "blocked": [
    {"team_key": "김세정", "platform": "instagram", "ref": "official_kimsejeong",
     "reason": "동명 — 아이돌 출신 가수 계정, 우리 팀은 인디", "checked": "2026-11-28", "by": "사람 확인"}
  ]
}
```

- 적용 위치: `export_lab_data.link_rows()` 바로 앞에서 `(team_key, platform, ref 또는 정규화한 주소)` 가 목록에 있으면 뺀다 → links.csv·사진·바로 듣기·팔로워 관찰 목록에 모두 반영. `collect_yt_channels`·`followers_watch` 도 같은 목록을 읽어 후보에서 뺀다.
- 규칙: 근거(reason)와 확인 날짜 필수(`config/debut_overrides.json` 과 같은 원칙), 한 번 막은 연결은 다른 출처에서 다시 들어와도 막힌다.
- 위 예의 김세정은 아직 '애매'라 **사람 확인 뒤에만** 넣는다(지금 파일은 만들지 않음).
