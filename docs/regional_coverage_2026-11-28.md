# 지방 공연장·지역 페스티벌 기록 보강 (2026-11-28)

> 사용자 지적: "지역별 공연장 정보 수집이 덜 된 것 같음. 예: 세종 누리락은 공연한 아티스트가 더 있을 텐데, 세종 보헤미안 페스티벌 같은 건 세부가 부족함."
> 결론: **맞는 지적.** 지방 공연은 인디스트릿·인디고에 올라온 것만 잡혔다. 세종부터 공연장 누리집을 직접 읽어 채웠다 — 세종 최근 2년 **공연 2 → 41건, 출연 팀 2 → 80팀**.
> 세종 밖 도시는 원인을 찾고 출처 후보를 정리하는 데까지 했다 (아래 5절). 인천은 1건 추가.

## 1. 왜 비었나 (원인)

| 대상 | 우리 데이터 (보강 전) | 원인 |
|---|---|---|
| 세종 음악창작소 누리락 | 최근 2년 공연 2건 (디깅라이브세종 EP.23 우희준 1건 + 너드커넥션 1건) | **출처가 안 닿음.** 공연장 마스터에는 있었음. 누리락은 자기 누리집(nurirock.or.kr)·NOL티켓으로 공연을 팔고, 인디스트릿에는 23회 중 1회만 올라옴 |
| 세종보헤미안뮤직페스티벌 | 0건 | **공연장 마스터에 없음 + 출처가 안 닿음.** 장소(세종중앙공원 도시축제마당)가 마스터에 없었고, 출연진은 누리락 누리집의 포스터·타임테이블 **그림**에만 있음 (글자 없음) |
| 세종보헤미안스테이지 (6월, 세종예술의전당) | 0건 | 위와 같음 (세종예술의전당도 마스터에 없었음) |
| '보헤미안 소극장' | 7건 | 이름이 비슷하지만 **광주** 동구의 다른 공연장 — 세종 페스티벌과 무관 |

누리락 인스타(@nurirock)는 라인업 계정 목록(config/insta_accounts.json)에 있지만 지금까지 모인 글이 없다.

## 2. 점검 방법

- 스크립트: `python3 scripts/collect_regional_audit.py [--exclude regional] [--json 결과.json]`
- 범위: 공연장 마스터(config/venues_kr.json) 중 서울 밖·폐업/휴업 아닌 곳.
- 기간: 최근 2년 (2024-11-28 ~ 2026-11-28, 이미 표가 나온 예정 공연 포함).
- 셈: 공연 1건 = 같은 공연장·같은 날·같은 제목. 출연 팀 = 이름 정규화(normalize.artist_key)로 묶은 수.
- 읽는 것: 공연 원본(data/raw/raw_kr_gig_*.csv) + 공연장 인스타 라인업 글(raw_press 의 venue_lineup). 공연장 짝 맞추기는 scripts/venues_kr.py 와 같다.
- '보강 전' = `--exclude regional` (이번에 만든 원본 파일을 빼고 셈).

## 6. 앱에 보이려면 (다른 담당 파일 — 바꿀 곳만 적음)

1. `scripts/csv_schema.py` GIG_SOURCES 에 `"regional"` 추가 → `scripts/collect_regional_gigs.py` 의 `SOURCE = "manual"` 을 `"regional"` 로. (지금은 스키마에 맞추려고 manual 을 씀. source_id 는 `nurirock:<번호>` / `lineup:<날짜>` 로 출처를 남김.)
   `config/source_roles.json` 에 `"공연:regional": {"role": "pending", "reason": "지역 공연장 누리집·포스터, 2026-11부터"}`.
2. `scripts/daily_run.sh` 수집 단계에 `python3 scripts/collect_regional_gigs.py` 한 줄 (누리락 목록은 천천히 바뀌니 주 1회도 충분).
3. 적재·내보내기(load_pg → export_lab_data)를 돌려야 signals.csv·공연장 화면에 반영된다. 이번 작업에서는 공유 데이터라 돌리지 않았다.
4. 같은 공연이 인디스트릿·누리락 양쪽에 있으면 출처만 다른 두 행이 된다 (예: 2026-11-28 우희준). 공연장별 공연 수는 같은 날 1건으로 세므로 영향 없음.
5. 세종보헤미안뮤직페스티벌을 scripts/festival_profiles.py 의 페스티벌 목록에 넣으면 '페스티벌' 화면에서 신인 비율을 볼 수 있다 (지금은 정답·선정 프로그램만 페스티벌로 봄).
