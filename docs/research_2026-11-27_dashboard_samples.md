# 음악 업계·스카우팅 대시보드 샘플 조사 (2026-11-27)

목적: 앞선 일반 분석 대시보드 조사(`docs/research_2026-11-27_dashboard_patterns.md` — Tableau·Observable·Kworb·OWID·PostHog)와 겹치지 않게, **음악 업계 A&R(신인 발굴) 도구와 스포츠 스카우팅 화면 7곳**을 살펴본다. 특히 **① 목록에서 오늘 볼 대상을 어떻게 고르고 강조하는지**, **② 한 아티스트(선수)를 눌렀을 때 타임라인·출처·지표를 어떻게 펼쳐 보여 주는지**를 집중적으로 보고 우리 대시보드(`docs/dashboard.html`) 재설계에 바로 반영한다.

조사 방법: 로그인이 필요한 유료 서비스(Chartmetric·Soundcharts·Songstats·Viberate·Spotify for Artists)는 공개 소개 페이지·기능 안내·도움말 문서 기준으로 확인했다.

## 1. 사례 7개

### ① Chartmetric — 아티스트 페이지 · Trending · Neighboring Artists
- 링크: https://chartmetric.com/ (기능 소개·도움말 기준)
- **첫 화면 구성**: 맨 위에 아티스트 기본 정보(장르·활동 단계·총합 점수)와 **'눈에 띄는 변화(Noteworthy Insights)'** 카드가 먼저 뜬다. 평범한 숫자는 뒤로 숨기고, 평소보다 갑자기 튄 지표(팔로워 급증, 플레이리스트 추가 등)만 골라 첫 화면에 올린다. 전체 목록 화면(Talent Search / Trending)은 상단 필터 바(장르·활동 단계·국가·성장 속도) + 순위 표 구조다.
- **'한 아티스트 상세' 보여주기**:
  - **타임라인(Milestones)**: 큰 플레이리스트 입성, 팔로워 기준 돌파, 공연/페스티벌 출연 같은 사건을 시간순으로 자동 기록한다. 중요한 점은 아티스트 규모에 맞춰 기준을 달리 잡는다는 것(신인은 작은 성과도 사건으로 표시).
  - **출처·지표**: 40여 개 플랫폼 지표를 한곳에 모으되, **누적 팬 규모(Fan Base Score)**와 **최근 반응 속도(Engagement Score)**를 둘로 갈라 보여 준다.
  - **비교(Neighboring Artists)**: 비슷한 규모·장르의 동료 아티스트를 위아래 10~50팀씩 나란히 놓아 "지금 이 팀이 또래 중에서 어느 위치인가"를 바로 가늠하게 한다.
- **'목록에서 누구를 볼지' 정렬·강조**: 누적 크기가 아니라 **최근 7일 변화율(% 증가)**로 정렬하는 'Trending' 목록을 따로 둔다. 장르·활동 단계(신인/중견/메이저) 필터가 필수다.
- **우리에게 가져올 점**:
  1. **크기(팬 수)와 최근 신호(갈래 겹침·최근 활동)를 분리**해서 보여 주고, 이미 큰 팀은 아예 단계 필터·제외 목록으로 걸러내기.
  2. 아티스트를 눌렀을 때 **사건 타임라인(언제 어떤 공연·발매·선정·매거진 언급이 있었나)**을 시간순으로 펼쳐 "왜 이 팀이 후보인지" 한눈에 근거를 제시하기.

### ② Soundcharts — 아티스트 대시보드 · 알림 센터 · A&R 스크리닝
- 링크: https://soundcharts.com/
- **첫 화면 구성**: A&R 담당자용 화면은 **관심 목록(Watchlist)**과 **실시간 알림 피드(Alerts Center)**가 중심이다. 차트 진입·라디오 첫 송출·플레이리스트 추가 같은 사건이 생기면 바로 맨 위에 뜬다.
- **'한 아티스트 상세' 보여주기**:
  - **타임라인·출처**: 첫 라디오 송출, 첫 차트 진입, 플레이리스트 추가 등을 출처 플랫폼 아이콘·날짜와 함께 시간순으로 쌓아 둔다.
  - **지표**: 전체 크기 점수(0~100) 옆에 **성장 속도 표시(Growth Speed, 최근 4주·9주 변화)**를 나란히 붙여 "이미 큰 팀"과 "지금 빠르게 크는 신인"을 구별한다. 틱톡 언급과 스포티파이 청취처럼 **서로 다른 갈래 신호가 같이 움직이는지** 교차 확인하는 화면이 핵심이다.
- **'목록에서 누구를 볼지' 정렬·강조**: **차단 목록(Blocklist)** 기능이 따로 있다. 이미 메이저 계약을 했거나 너무 유명한 팀을 목록에서 영구 제외해 발굴 잡음을 줄인다. 기준치(예: 최근 7일 N% 이상 상승)를 넘긴 팀만 강조한다.
- **우리에게 가져올 점**:
  1. **유명 팀 차단 목록(Blocklist)** 개념을 그대로 도입 — 프로필 데이터가 아직 없는 메이저 팀(혁오·콜드 등)도 수동 제외 목록으로 깔끔하게 걸러내고, '제외한 팀' 접기 목록에 이유를 투명하게 남기기.
  2. **최근 큐레이션/매거진·인스타 언급 피드**를 별도 영역으로 두어, "방금 어떤 신인이 어디서 언급됐나"를 알림처럼 바로 훑기.

### ③ Songstats — 실시간 Activity Feed · Playlist Journey
- 링크: https://songstats.com/
- **첫 화면 구성**: 요약 숫자(누적 스트림·팔로워·도달)와 기간 전환(최근 7일 / 28일 / 전체) 아래, **실시간 활동 피드(Activity Feed)**가 SNS 타임라인처럼 세로로 흐른다.
- **'한 아티스트 상세' 보여주기**:
  - **타임라인**: 플레이리스트 추가, 차트 진입, DJ 서포트, 라디오 송출, 소셜 언급을 **시간 역순 피드**로 나열한다. 각 항목마다 출처 플랫폼 배지 + 날짜 + 원문/플레이리스트 링크가 붙는다.
  - **Playlist Journey**: 첫 신호가 어떻게 다음 큐레이션으로 번져 나갔는지 흐름을 한눈에 보여 주어, 반짝 화제인지 꾸준한 지지가 쌓이는지 구별한다.
  - **지표**: 플랫폼별 필터 버튼(Spotify, YouTube, TikTok 등)으로 어떤 출처에서 반응이 나오는지 바로 좁혀 볼 수 있다.
- **'목록에서 누구를 볼지' 정렬·강조**: 마일스톤(새 기록 달성)에 색 배지를 붙여 시선을 먼저 끌고, 기간 필터로 최근 움직임이 있는 항목만 위로 올린다.
- **우리에게 가져올 점**:
  1. 한 팀을 눌렀을 때 펼쳐지는 **신호 타임라인에 갈래 배지(공연/발매/선정/큐레이션) + 날짜 + 출처 이름 + 클릭 가능한 원문 링크**를 Songstats 활동 피드처럼 깔끔하게 붙이기.
  2. 빈 지표 칸을 억지로 0이나 공백으로 채우지 않고, **실제 확보된 출처·사건만** 선명하게 보여 주기.

### ④ Viberate — A&R 발굴 차트 (Artist Discovery Chart)
- 링크: https://www.viberate.com/
- **첫 화면 구성**: 첫 화면부터 바로 **필터 칩 + 순위 표**다. 위쪽에 "HOT", "Trending on", **"인디/무소속(Other Indie / Unsigned)"**, 장르·세부장르, 국가·도시, 팔로워 상한선 같은 빠른 필터가 가로로 배치되어 있다.
- **'한 아티스트 상세' 보여주기**:
  - 표에서 한 줄을 누르면 아티스트 상세로 들어가 채널별 지표, 플레이리스트, 도시별 팬 분포를 본다.
  - 관심 아티스트를 팔로우(우선 추적)하면 매일 변화량을 우선 집계한다.
- **'목록에서 누구를 볼지' 정렬·강조**: **상한선 필터**(예: 팔로워 N명 이하, 무소속/인디만) + **"HOT" 강조 배지**로 '크지 않으면서 지금 뜨는 팀'을 맨 위에 띄운다. 하루·주·월 단위 상승폭으로 정렬한다.
- **우리에게 가져올 점**:
  1. 표 위에 **장르 칩 + 갈래 칩 + 신인/미정답 필터**를 한 줄로 놓아, 힙합·R&B·일렉트로닉·록/밴드·포크·재즈 등 원하는 장르만 한 번 눌러 바로 좁혀 보기.
  2. 상위 5팀은 표 속에 묻히지 않게 **'오늘 먼저 볼 후보 5팀' 카드**로 첫 화면에 강조하고, 나머지 전체는 아래 정렬 가능한 표로 분리하기.

### ⑤ Spotify for Artists — Home(로스터 대시보드) · Audience Segments
- 링크: https://artists.spotify.com/
- **첫 화면 구성**: 2026년 개편된 Home 화면은 **'지금 당장 볼 것'**을 맨 위에 모은다. 레이블·매니저용 로스터 대시보드는 여러 아티스트의 상태·발매 일정·핵심 숫자를 카드형으로 한눈에 비교한다.
- **'한 아티스트 상세' 보여주기**:
  - **단계 분류(Audience Segments)**: 전체 청취자를 '핵심 팬(Super) / 일반 활성 / 과거 활성 / 알고리즘 유입'으로 **상태 배지**처럼 또렷하게 나눈다. 단순히 총합 숫자만 보지 않고 "이 숫자가 어떤 성격인지"를 드러낸다.
  - **타임라인·출처**: 곡별 발매 타임라인과 유입 경로(직접 검색 vs 플레이리스트 vs 자동 재생)를 비율 막대로 비교한다.
- **'목록에서 누구를 볼지' 정렬·강조**: 숫자 카드마다 지난 28일 대비 증감 표시를 붙이고, 새 발매나 주요 이정표가 있는 아티스트 카드를 맨 앞에 배치한다.
- **우리에게 가져올 점**:
  1. 첫 화면(스크롤 전)에 **핵심 숫자 4개(비교값·맥락 한 줄 포함) + 오늘 볼 후보 카드 5장**이 바로 보이도록 화면 위계 잡기.
  2. 아티스트 상태를 "신인 확인 / 프로필 수집 중(확인 안 됨) / 기성"처럼 **성격이 바로 읽히는 배지**로 구분해, 정보 없음("모름")이 주는 혼란 없애기.

### ⑥ MusicBrainz & RateYourMusic(RYM) — 아티스트 메타데이터·장르·디스코그래피
- 링크: https://musicbrainz.org/ · https://rateyourmusic.com/
- **첫 화면 구성**: 검색·차트에서 아티스트를 선택하면 왼쪽 본문에 **종류별·연도순 발매 목록(정규/EP/싱글 분리)**, 오른쪽 사이드바에 **기본 정보(결성 연도, 지역, 별칭/동명 구분, 장르 태그)**가 정돈되어 나온다.
- **'한 아티스트 상세' 보여주기**:
  - **동명 구분·별칭(Disambiguation & Aliases)**: 같은 이름의 다른 팀이 있을 때 짧은 설명으로 구분하고, 한/영 표기나 옛 이름을 '별칭'으로 묶어 보여 준다.
  - **장르 계층**: RYM은 **대표 장르(Primary)**와 보조 장르, 분위기 태그를 분리해 한눈에 팀의 색깔을 읽게 한다. MusicBrainz는 검증된 공식 장르 목록과 일반 태그를 구분한다.
  - **출처 투명성**: 발매 연도·레이블·외부 링크(위키·공식 사이트)가 표에 함께 붙어 사실 확인이 쉽다.
- **'목록에서 누구를 볼지' 정렬·강조**: RYM 차트는 장르·연도·최소 평가 수(표본 하한선)로 걸러 표본이 너무 적은 왜곡을 막는다.
- **우리에게 가져올 점**:
  1. 우리 `config/genre_map.json`의 큰 장르 갈래(힙합·R&B·일렉트로닉·재즈·포크·록/밴드·인디팝)를 **대표 장르 배지**로 아티스트 카드·표에 붙여 음악 색깔을 바로 읽기.
  2. 표본이 적은 항목(10팀 미만)은 흐리게 + 이유 범례를 분명히 적어, RYM의 최소 표본 기준처럼 숫자를 오해하지 않게 하기.

### ⑦ 스포츠 스카우팅 (FBref 구 스카우팅 리포트 · Hudl StatsBomb) — 유망주 비교 화면
- 링크: https://fbref.com/ · https://www.hudl.com/products/statsbomb
- **첫 화면 구성**: 선수 프로필 상단에 기본 정보(나이·포지션·소속·출전 시간 = 표본 크기)를 두고, 바로 아래에 **'스카우팅 요약(Scouting Report)' 가로 막대** 또는 **레이더 차트**를 놓아 3초 만에 강점·약점을 파악하게 한다.
- **'한 대상 상세' 보여주기**:
  - **백분위 가로 막대(FBref 방식)**: 절대 수치 옆에 **같은 포지션·같은 리그 또래 대비 몇 % 위치인지** 가로 막대로 그린다. 절대값만 보면 "이게 높은 건지 낮은 건지" 모르는데, 기준선(또래 평균/중앙값)과 비교해 바로 해석이 된다.
  - **비슷한 선수(Similar Players)**: 요약 지표가 가장 가까운 선수 10명을 자동 추천한다.
  - **표본 하한 표시**: 최소 출전 시간(예: 900분 이상)을 채우지 못하면 비교에서 빼거나 경고를 띄운다. (참고: FBref는 2026년 1월 데이터 계약 종료로 고급 리포트를 내렸지만, 레이아웃 문법은 업계 표준으로 남아 있다.)
- **'목록에서 누구를 볼지' 정렬·강조**: 전체 선수를 섞지 않고 **리그 수준(빅5 vs 차상위 14개 리그)과 포지션**으로 먼저 묶은 뒤 비교한다.
- **우리에게 가져올 점**:
  1. 모든 비율·분포 그래프에 **비교 기준선(아무 신호 기준선, 리드타임 중앙값 세로선)**과 막대 끝 숫자(`p% (k/n)`)를 직접 적어, 차트를 보자마자 "기준보다 몇 배 높은지" 해석되게 하기.
  2. 후보 카드에 **"왜 이 팀인가"를 한 줄 요약 + 갈래 겹침 막대/배지**로 압축해, 글자 벽 없이 3초 만에 훑을 수 있게 만들기.
