# Chartmetric 기준 다시 점검 — 화면·기능·분석 로직, 우리에게 빠진 것 (2026-11-28)

> **왜:** 사용자 지시 "기본적인 UI/UX는 Chartmetric 바탕으로, 거기 있는 팀 사진이나 바로 들을 수 있는 것, 데이터 분석 로직과 화면 배치를 한 번 더 점검하고 우리 것에서 빠진 것 확인해 추가".
> **근거:** 직접 본 화면 기록 — [Chartmetric 아티스트](research_2026-11-27_chartmetric_artist.md) · [Chartmetric 공연](research_2026-11-27_chartmetric_live.md) · [Viberate 안쪽](research_2026-11-27_viberate_inside.md) · [디자인 기준서](design_spec_from_chartmetric.md) · [구조 v2](app_structure_v2.md).
> **표 읽는 법:** 우선순위 **상** = 이번에 바로 구현 · **중** = 우리 데이터로 가능, 다음 차례 · **하** = 데이터가 없거나 효과가 작음. '✅ 이번에 함'은 이 문서와 같은 날 앱에 넣은 것.

## 0. 한눈에

- **구조(메뉴·검색·팀 탭·발굴 필터·차트·공연장/도시/페스티벌·알림·내 목록)는 v2에서 거의 다 맞췄습니다.** 그래서 빠진 것은 '뼈대'가 아니라 **손에 닿는 부분** 쪽이었습니다.
  1. **바로 듣기가 화면마다 제각각이었습니다.** 스포티파이 링크가 있는 팀만 그 자리에 플레이어가 펼쳐졌고, 페이지를 옮기면 소리가 끊겼습니다. 차트·알림·검색 결과·미리보기에는 버튼이 아예 없었습니다. → ✅ **화면 아래 고정 미니 플레이어** + 모든 팀 목록에 '▶'.
  2. **팀 사진이 빠진 목록이 있었습니다** (차트·알림·색 지도). → ✅ 사진(없으면 머리글자) 추가.
  3. **팀 머리에 '숫자 몇 개 + 출처 아이콘' 줄이 없었습니다** (Chartmetric 아티스트 머리 지표 타일·연결 플랫폼 아이콘). → ✅ 핵심 숫자 4칸 + 연결 플랫폼 아이콘 줄.
- **분석 로직은 이미 '그들 원리 + 우리 데이터'로 옮겨져 있습니다** (4칸 상태 카드, 같은 체급 비교 등급, 사건 별점, 사건 전후 28일, 저장 필터 알림, 공연장 구독 알림). 남은 차이는 **'팀 나란히 비교'**, **'이상치 문장(평소보다 ○배)'의 팀 화면 표시**, **'비슷한 팀' 유사도·가중치 조절** 세 가지입니다.

## 3. 이번에 구현한 것 (2026-11-28)

1. **화면 아래 고정 미니 플레이어** (`docs/app/components/mini_player.js`, `docs/app/css/player.css`)
   - 어느 화면이든 '▶'(`data-play-team`)를 누르면 아래 띠에서 재생, **다른 페이지로 옮겨도 계속**(본문 바깥에 한 번만 만듦).
   - 고르는 순서 (`docs/app/player_pick.js`, 테스트 `tests/js/player_pick.test.mjs`): ① `players.csv`(다른 작업자가 만드는 대표곡 표) → ② 스포티파이 아티스트(인기곡) → ③ 무대 영상(무대 → 공식 라이브 → 공식 → 검색, 최신 먼저, 최대 3개). 띠의 '스포티파이 인기곡 · 유튜브 영상 1·2·3' 단추로 바꿔 듣기, 유튜브는 '크게'.
   - 같은 팀 ▶를 다시 누르면 닫힘, 재생 중인 팀 버튼은 ■로 표시. 플레이어가 열리면 본문 아래 여백·알림 상자 위치를 띠 높이만큼 올림. 휴대폰 폭에서는 곡 고르기 단추가 옆으로 밀리는 한 줄.
   - `players.csv`는 `meta.json` 보조 파일 목록(extras)에 있을 때만 받음 → 없는 파일 404 없음. `scripts/update_meta_extras.py` EXTRAS에 `players.csv` 추가(테스트 포함).
   - 무대 영상 표(0.7MB)는 여전히 늦게 받음: 받기 전 화면엔 '자리'만 두고, 화면을 다 그린 뒤 한가할 때 받아서 ▶로 채움(첫 화면 속도 그대로).
2. **'▶'·사진을 모든 팀 목록에**: 후보 표·색 지도·차트·미리보기·팀 머리·알림(홈·알림 화면)·검색 결과 + 원래 듣기 버튼이 있던 홈·관심·공연장(모두 미니 플레이어로 바뀜). 깨진 사진은 앱 전체에서 머리글자로 바꿈. 사진 허용 주소에 유튜브 채널 썸네일(ytimg·ggpht) 추가.
3. **팀 머리 '핵심 숫자 4개 + 출처 아이콘' 줄** (`docs/app/team_keystats.js`, 테스트 `tests/js/team_keystats.test.mjs`): 발굴 점수(순위·지난주 ▲▼) · 지난 1년 공연(최근 2년 공연장 수) · 매거진·큐레이션 소개(맥락 매체 따로) · 무대 영상(최근 날짜) + 연결 플랫폼 아이콘(스포티파이·유튜브·인스타·멜론·벅스·지니, 글자 동그라미 — 상표 그림 안 씀). 값이 없으면 '—'(0점 아님) + 이유 말풍선. '신호 갈래'는 바로 아래 4칸 카드와 겹쳐 뺌.
