# 음악 분석 서비스 4곳의 분석·검증 로직 → Gigle Research에 대입 (2026-11-27)

> **읽기 전에:** 이 문서는 **로그인 없이 볼 수 있는 공개 자료**(제품 소개 페이지·공식 도움말·공식 블로그·방법론 글)만 보고 정리했습니다. 서비스 안쪽 화면이나 실제 계산식은 보지 못했으므로, **"공개 설명 기준이라 실제와 다를 수 있음"** 이 문서 전체에 해당합니다. 유료 서비스의 데이터는 옮기지 않았고, 화면 구성·기능·방법론 설명만 요약했습니다. 출처 링크는 각 줄에 붙였습니다.
>
> 비교 대상: **Chartmetric**(차트메트릭) · **Viberate**(바이브레이트) · **Soundcharts**(사운드차트) · **Songstats**(송스태츠). 사용자가 준 3개 페이지(orphiq 비교 글, Viberate 가입 화면, Chartmetric 공연·공연장 활용 사례)에서 출발했습니다.

## 0. 한눈에 보는 결론

**핵심 발견 5개**

1. **네 곳 모두 '예측이 맞았는지'를 숫자로 공개하지 않습니다.** 적중률·백테스트(과거로 돌아가 맞혀 보기)·선행 기간 같은 검증 숫자를 찾지 못했습니다. Chartmetric은 오히려 화면의 신호를 "예측이 아니라 조사용 맥락으로 쓰라"고 적어 두었고([A&R 활용 사례](https://chartmetric.com/use-cases/music-analytics-for-a-and-r)), 사례 연구에서도 "어떤 신호가 아티스트 성과를 일으켰다고 주장하지 않는다"고 씁니다([사례 연구](https://chartmetric.com/case-studies/global-talent-agency-scouting)). → **검증을 공개하는 것은 우리가 앞선 부분입니다.**
2. **그들의 '경력 단계'와 '모멘텀'은 예측 모델이 아니라 '사람이 고르기 쉽게 나누는 장치'입니다.** Chartmetric 경력 단계 = 지난 1년 점수의 **중앙값**으로 순위 구간을 나눈 것, 모멘텀 = 최근 30일 평균과 60일 평균의 차이를 **같은 단계 안에서만** 비교한 것([경력 단계·성장 설명, 2022](https://hmc.chartmetric.com/chartmetric-artist-career-stage-growth/)). 우리 실험에서도 '신호 가속도'·'선정 단계 상승' 같은 모멘텀형 특징은 점수를 올리지 못했습니다([점수 새 특징 실험](feature_lab.md)). → **우리도 점수를 바꾸는 대신 '화면의 칸·필터'로 들이는 게 맞습니다.**
3. **Chartmetric 공연 기능의 핵심은 '공연장 사다리'(Venue Journey)입니다.** 어떤 공연장에 선 팀들이 **그 전과 그 뒤에 어느 규모의 공연장에 섰는지**를 1·3·5년·전체 기간으로 보여 줍니다([공연·공연장 페이지](https://chartmetric.com/use-cases/live-events-venues)). 우리는 공연 기록·같은 무대·씬 묶음은 있지만, **공연장 체급(수용 인원)과 '다음 공연장' 흐름은 없습니다.** 우리 공연 데이터로 바로 만들 수 있는, 가장 비슷하면서도 빠진 기능입니다.
4. **그들의 강점은 '검증'이 아니라 '데이터의 폭과 신원 관리'입니다.** Chartmetric은 스포티파이·애플·인스타 계정 번호를 하나의 아티스트로 묶고 곡은 ISRC(곡 고유 번호)로 묶습니다([데이터 항목 설명](https://chartmetric.com/data/entities)). Viberate는 사람이 검수하고 사용자 제보를 큐레이터가 승인하는 방식으로 "중복 항목이 전혀 없다"고 주장합니다([Viberate 도움말](https://www.viberate.com/help/what-makes-viberate-different-from-other-music-analytics-tools/)). 우리는 아직 **이름 중심**으로 팀을 잇고 있어(동명 팀 위험) 이 부분이 뒤처집니다.
5. **알림은 세 곳(Soundcharts·Songstats·Viberate)의 공통 기본 기능입니다.** 차트 진입·플레이리스트 추가·라디오 방송·급상승·순위 도달을 알려 줍니다. 우리는 매일 데이터가 쌓이는데도 **'관심 팀에 새 신호가 생겼다'는 알림이 없습니다.**

**우리에게 가장 급한 보강 3개** (자세한 근거는 D절)

| 순위 | 보강 | 왜 급한가 | 필요한 것 |
|---|---|---|---|
| 1 | **공연장 사다리 + 공연장 체급** (Chartmetric Venue Journey의 국내 인디판) | 사용자가 '가장 비슷하다'고 본 기능의 핵심이고, 우리 공연 기록(인디스트릿 2024~·상상마당 2010~)으로 바로 계산 가능 | 공연장 205곳 중 상위 50~100곳 수용 인원(공식 홈페이지·대관 안내에서 사람이 확인), 공연 기록의 날짜·공연장 |
| 2 | **발굴 단계 + 단계 안 모멘텀** (점수 말고 화면 칸·필터로) | "이 팀이 지금 어디쯤이고, 같은 단계 팀들보다 빨리 움직이는가"를 담당자가 한눈에 보게 함. 점수에 넣으려면 먼저 백테스트 통과 필요 | 이미 있는 신호·선정·정답 데이터 + 매일 점수 스냅샷. 기준일 시점 규칙 그대로 적용 |
| 3 | **ID 기반 팀 신원 확정 + 출처 표시 + 오류 신고 칸** | 검증의 바닥은 '같은 팀을 같은 팀으로 세는 것'. 동명 팀 섞임은 백테스트 숫자 자체를 흔듦 | 멜론 아티스트 번호·스포티파이 번호·인스타 계정을 팀 키의 기준으로, 이름은 보조로 |

## A. 세 페이지의 구성 요약

### A1. orphiq — "Chartmetric vs Soundcharts vs Songstats vs Viberate" 비교 글
- 주소: https://orphiq.com/resources/music-analytics-platforms-compared (작성 2026-10-21, 갱신 2026-11-20)
- **주의:** 쓴 곳(Orphiq)이 자체 유료 서비스(발매 계획 도구·AI 전략 도우미)를 파는 회사입니다. 네 서비스와 '보완 관계'라고 소개하지만 객관적인 제3자 평가는 아닙니다.
- 목차: 누가 유료 분석 도구가 필요한가 → 기능 비교표 → 가격 비교표 → Soundcharts vs Chartmetric → 서비스별 강점 → 솔직한 비교 → 고르는 법 → **네 곳의 데이터 정확도** → 자주 묻는 질문
- 기능 비교표의 칸: 스트리밍 출처 · 플레이리스트 추적 · 라디오 모니터링 · 소셜 추적 · **아티스트 발굴 도구** · 팀 협업 · 리포트 · 모바일 앱 · API
- 서비스별 한 줄 평(이 글의 주장):
  - Chartmetric = **발굴**이 강점(성장 속도·지역 플레이리스트 추가·틱톡 속도·샤잠 급등 필터). 화면이 빽빽해 익히는 데 일주일.
  - Soundcharts = **라디오**가 강점, 팀 작업 공간·고객용 리포트.
  - Songstats = **실시간 알림**·모바일 우선, 라디오 5만 곳 이상(Radiostats), DJ 플레이(1001Tracklists).
  - Viberate = **공연·페스티벌 조사**(라인업 분석·관객 구성·공연장/공연 탐색), A&R 필터.
- 정확도 절의 요지: "어떤 외부 분석 도구도 100% 정확하지 않다", 스포티파이·애플 아티스트용 화면이 진짜 기준, 스트리밍은 수 시간~하루 늦고, 작은·비공개 플레이리스트는 놓칠 수 있다. **예측 점수나 아티스트 매칭 방법에 대한 언급은 없음.**

### A2. Viberate — 가입(온보딩) 화면 → 공개 사이트로 대신
- https://app.viberate.com/onboarding/basic-info/ 는 브라우저에서 그려지는 화면이라 **로그인 없이 내용(질문 항목)을 읽을 수 없었습니다.** 공개 사이트로 대신 정리했습니다.
- 공개 사이트 메뉴([viberate.com](https://www.viberate.com/)):
  - **기능:** 아티스트·곡·플레이리스트·관객 분석, 차트, 아티스트 비교, **페스티벌 분석**, 업계 동향
  - **채널:** 스포티파이·애플뮤직·유튜브·라디오·인스타·틱톡·비트포트·페이스북·샤잠·사운드클라우드
  - **활용 대상:** A&R 팀 · **공연 기획자** · 매니저 · 마케터 · 데이터 분석가
- 차트 페이지([music-charts](https://www.viberate.com/music-analytics/music-charts/)): 아티스트·곡·플레이리스트·**페스티벌**·레이블 순위를 매일 갱신, 아티스트 차트에 **'HOT' 필터**(뜨는 팀)와 **A&R 필터**(장르·국가·기간·팬 규모).
- 페스티벌 분석([festival-analytics](https://www.viberate.com/festival-analytics/)): 장르 구성, 라인업 분석, 관객 구성, 지역·장르 안 페스티벌 순위.
- 공연 분석(첫 화면 설명): 도시·공연장 규모·장르로 공연 탐색, 라인업·수용 인원·장르 태그, 공연장 종류(클럽·아레나), 예상 관객 범위.

### A3. Chartmetric — 공연·공연장 활용 사례 (사용자가 '가장 비슷하다'고 한 곳)
- 주소: https://chartmetric.com/use-cases/live-events-venues — 대상: 공연 기획자·섭외 담당·에이전트·레이블·아티스트 팀
- 제목: "아티스트가 어디서 공연하는지, **다음엔 어디로 가는지** 보라"
- 4개 구역:

| 구역 | 보여 주는 것 |
|---|---|
| **아티스트 공연 이력** | 공연·페스티벌 이력(날짜·상태·공연장·수용 인원), 공연마다 공연장·지역·가격·**라인업 역할**(헤드라이너/서포트)·**출처 표시**, 시기별·지역별 공연 추이, 자주 선 공연장, **함께 선 아티스트**, 지역 확장, '최근 8주 모멘텀'(스포티파이·애플·틱톡) |
| **페스티벌 분석** | 페스티벌 순위·점수 + 라인업 표(정렬·필터·CSV), 라인업 안 아티스트 비교, 라인업 전체의 관객 구성·장르·국적, 비슷한 페스티벌(국가·장르) |
| **공연장 분석** | 수용 인원·주소·최근 공연·가장 큰 아티스트, 공연 이력 검색, 과거 출연자 장르 분포, **Venue Journey(공연장 사다리)** — 이 공연장에 선 팀들이 그 전·후 어느 공연장에 섰는지(1·3·5년·전체, 수용 인원 기준) |
| **시장 탐색** | 도시·국가·수용 인원·예정 공연으로 공연장 목록 거르기, 페스티벌 목록, 도시별 공연 타임라인과 상위 아티스트, '도시별 월간 청취자 비율' 예시 위젯 |

- 자주 묻는 질문 제목에 "**빠진 공연을 고객이 제보할 수 있나?**"가 있음(답은 접혀 있어 못 읽음).
- **이 페이지에는 계산식·데이터 출처(송킥·밴즈인타운 등)·예측 주장·고객 사례가 없습니다.** 순위·점수, 공연장 사다리의 체급 기준은 이름만 나오고 정의는 없습니다.

## B. 서비스별 핵심 지표·점수 — 공개 설명 기준 (실제와 다를 수 있음)

### B1. Chartmetric

| 지표 | 공개된 설명 | 출처 |
|---|---|---|
| **아티스트 점수 (Artist Score)** | 0~100점. '팬 규모'(팔로워·구독자처럼 오래 쌓인 수)와 '참여'(스트리밍·플레이리스트·좋아요·댓글처럼 최근 활동)를 섞되 **최근 참여에 더 무게**. 플랫폼 크기로 정규화, 매일 갱신. 2022년 설명은 "16개 플랫폼의 50개 넘는 지표를 한 숫자로", **공연 데이터는 포함 안 함**. 다른 아티스트들 성적에 따라서도 움직이는 **상대 점수** | [지표 설명 2025](https://hmc.chartmetric.com/what-is-chartmetric-score-career-stage-brand-affinity/), [경력 단계 2022](https://hmc.chartmetric.com/chartmetric-artist-career-stage-growth/) |
| **아티스트 순위 (Artist Rank)** | 모든 아티스트를 점수로 줄 세운 순위(완전히 상대적). 2021년에 상위 50만 → 100만 명으로 넓히며 "떠오르는 아티스트를 더 일찍 발견"하는 것을 목표로 듦(목표일 뿐 검증 아님) | [순위 개편 2021](https://hmc.chartmetric.com/cross-platform-performance-cpp-global-digital-artist-ranking/) |
| **경력 단계 (Career Stage)** | **지난 360일 점수의 중앙값**으로 계산(하루하루 튀는 값 무시), 주 2회 갱신. 2022년 기준: 레전더리(상위 1.2천 중 30년 넘은 팀)·슈퍼스타(상위 1.2천)·메인스트림(2천~8천위)·미드레벨(8천~3만위)·디벨로핑(나머지). 2025년 설명은 구간이 다르고(상위 약 1.5천/1.6천~1.2만/1.2만~3.5만/3.5만~10만/디벨로핑) **'이머징(플랫폼마다 아직 들쭉날쭉한 새 팀)'** 단계를 추가. 2025년 글은 예시 숫자가 자기 구간과 안 맞는 등 **설명이 서로 어긋남** | 위 두 글 |
| **경력 성장 (Career Growth, 2022)** | **최근 30일 점수 평균 − 최근 60일 평균**. **같은 경력 단계 안에서만 비교**해 표준편차로 등급: 폭발적(8 이상)·높음(3~8)·성장(약 3)·보합(약 0)·하락. "실시간 모멘텀용이 아님"이라고 스스로 적음 | [경력 단계 2022](https://hmc.chartmetric.com/chartmetric-artist-career-stage-growth/) |
| **최근 모멘텀 (Recent Momentum, 2025)** | 지난 12개월 점수의 **기울기**, 최근(특히 3개월)에 더 무게. 성장·강한 성장·폭발적 성장. 구간 기준 미공개 | [지표 설명 2025](https://hmc.chartmetric.com/what-is-chartmetric-score-career-stage-brand-affinity/) |

### D2. 공연·공연장: Chartmetric live events vs 우리 공연장·씬

| Chartmetric 공연 기능 | 우리 지금 | 차이와 할 일 |
|---|---|---|
| 아티스트 공연 이력(날짜·공연장·수용 인원·역할·출처) | 팀 상세 공연 표(날짜·공연장·출처 일부) | 수용 인원·역할·출처 칸 추가 |
| 함께 선 아티스트·자주 선 공연장 | ✅ 같은 무대 동료, 수상 팀과 같은 무대(점수 v2 가중치 2), 사운드 지도 | **우리가 더 깊음** — Chartmetric은 '함께 선 팀' 목록이지만, 우리는 이것을 점수 신호로 쓰고 효과를 검증함 |
| 공연장 페이지(수용 인원·최근 공연·가장 큰 아티스트·장르 분포·공연 이력) | 공연장·씬 화면: 이번 달 신인이 많이 선 공연장 TOP, 씬 묶음, 대표 공연장, 다가오는 공연 | 공연장 1곳짜리 상세 페이지가 없음 → **공연장 상세**(공연 이력·출연 장르 분포·'여기 섰던 팀 중 나중에 정답 받은 팀'·사다리) |
| **Venue Journey**(전·후 공연장, 수용 인원 기준) | ❌ | **공연장 사다리 만들기**(1순위 보강) |
| 시장 탐색(도시·수용 인원·예정 공연 필터) | 다가오는 공연(날짜·공연장 묶음) | 도시·체급 필터는 공연장 표가 생기면 |
| 페스티벌 순위·라인업 분석 | 없음 | 하순위 |
| 도시별 월간 청취자 | 없음(공개 데이터로 불가) | 공연 지역 분포로 대신 |
| 공연 데이터 출처 미공개 | ✅ 출처별 성적표까지 공개(인디스트릿 = 수상 팀 120팀 중 56팀을 먼저 잡음, 24팀은 여기에만) | **우리가 앞섬** — 공연 출처의 '발굴력'을 숫자로 잼 |

**공연장 사다리 설계안 (한국 인디판):**
1. 팀마다 공연을 날짜순으로 줄 세움(발굴 출처 공연만, 12팀 넘는 페스티벌은 따로).
2. 공연장마다 "여기 처음 선 팀들이 **그 전에 주로 선 곳** / **그 뒤 1년 안에 처음 선 곳**" 상위 5곳과 비율을 셈 → 공연장 상세에 화살표로 표시.
3. 체급: 수용 인원을 모은 공연장은 소(~150)·중(~400)·대(400~)로, 못 모은 곳은 '체급 미상'. 팀이 처음으로 한 단계 큰 공연장에 서면 **'체급 상승'** 이벤트.
4. 검증: '체급 상승' 이벤트를 기준일 시점 규칙으로 백테스트 — 체급 상승한 팀의 이후 정답 비율 vs 기준선. **점수에 넣는 것은 교차 검증을 통과했을 때만.** (참고: 비슷한 '공연장 질' 특징은 효과가 없었으니 기대는 낮게 잡고, 우선 **설명·탐색 화면**으로 가치가 있음)
5. 시점 주의: 수용 인원은 '지금' 값이라, 공연장이 확장·이전한 경우 과거와 다를 수 있음 → 공연장 표에 '확인일'을 적어 둠.

### D3. '경력 단계'를 우리 식으로: **발굴 단계**

Chartmetric 경력 단계는 '인기 순위 구간'입니다. 우리는 인기 수치가 거의 없으므로 **'어디까지 인정받았나'** 를 단계로 씁니다. 모두 기준일 전 정보만으로 계산(시점 누수 방지).

| 단계 | 정의 (안) | 화면에서 |
|---|---|---|
| 0 백지 | 첫 발매 뒤 남이 다룬 신호가 아직 없음 (데뷔 코호트의 '미언급') | 갓 데뷔 탭(있음) |
| 1 첫 신호 | 발굴 출처 신호 1갈래 | 후보 목록 |
| 2 여러 갈래 | 공연·큐레이션·선정 중 2갈래 이상, 또는 서로 다른 공연장 3곳 이상 | 후보 목록 |
| 3 선정·중간 정답 | 선정 단계 '선정' 이상, 또는 B등급 정답 | 후보 목록 상단 |
| 4 졸업 | S·A 정답을 받음 → 후보에서 빠지고 '적중 사례'로 | 검증 화면 |
| 제외 | 유명 팀(팬 1만 이상 등), 신인 기준 밖 | 숨김 |

- **Chartmetric에서 가져올 설계 3가지:** ① 단계는 **긴 기간의 안정된 값**(우리는 '최고 단계 도달'이라 자연히 안정), ② **모멘텀은 같은 단계 안에서만 비교**(단계 1 팀끼리, 단계 2 팀끼리), ③ 단계와 모멘텀을 **필터·칸**으로 노출.
- **모멘텀 (우리 데이터로):** 기준일마다 v2 점수를 다시 계산할 수 있으므로 "최근 30일 점수 평균 − 최근 60일 평균"을 단계 안 표준편차로 나눔 → 폭발·상승·보합·하락. 매일 스냅샷이 쌓이면 그것으로 대체.
- **정직한 주의:** 우리 실험에서 '신호 가속도'(−0.003)·'선정 단계 상승'(−0.012)은 점수를 올리지 못했습니다. 그래서 단계·모멘텀은 **점수가 아니라 '어떤 팀부터 볼지' 정하는 화면 도구**로 들이고, 점수 반영은 별도 백테스트를 통과했을 때만 합니다(점수 정의 변경이라 사용자 확인 필요).

### D4. 우리가 앞선 점과 뒤처진 점 (정직하게)

**앞선 점**
- **검증을 숫자로 공개:** 기준일 6개 교차 검증, 등급 가중 AUC 약 0.79, 상위 50 적중, 95% 구간까지([methods](methods.md)). 네 곳 모두 공개한 적중률이 없음.
- **시점 누수 방지 규칙:** 날짜를 일부만 알 때 보수적으로, 기준일 전·후 분리, 유명 판정은 과거 기준일에 안 씀([rule_leakage](rule_leakage.md)).
- **같은 집안 규칙:** 신호 출처와 정답 주최가 같으면 적중으로 안 셈(힙합엘이↔한국힙합어워즈)([same_house](same_house.md)). 이런 이해관계 점검은 공개 자료 어디에도 없음.
- **출처 성적표와 역할 분류:** 출처마다 '먼저·정확하게·유일하게 짚었나'를 재서 발굴·맥락·제외·검증 대기로 나눔([source_roles](source_roles.md)).
- **'성공'의 정의를 고정:** 정답 프로그램과 S·A·B 등급을 먼저 정함.
- **국내 인디 오프라인 신호:** 라이브 클럽 공연·지원 사업 선정·국내 매거진. 그들은 스트리밍·소셜 중심이라 이 층이 얇을 것으로 **추정**(로그인해서 확인할 질문, E절).
- **실패도 공개:** 놓친 팀 분석·장르 편향(힙합·R&B가 상위 100에 거의 없음).

**뒤처진 점**
- 데이터의 폭과 갱신(그들: 16개 플랫폼 매일, 우리: 반응 지표는 이제 쌓기 시작).
- **이름 중심 매칭**(동명 팀 위험), 인스타 연결률 39%.
- 공연장 체급·지역 정보 없음 → 사다리·지역 확장 분석 불가.
- 알림·오류 제보·출처 표시 같은 '쓰는 사람용' 기본기.
- 표본이 작음(기준일마다 정답 4~23팀) — 0.01 차이는 흔들림.

## E. 로그인(무료 체험)해서 확인할 화면·질문 목록

> 원칙: 화면 구성과 정의(도움말 말풍선·설명)만 메모하고, **데이터를 대량으로 내려받거나 저장소에 옮기지 않습니다.** 팀 몇 개를 '확인용'으로 검색하는 정도로만 씁니다. 확인용 팀은 우리 쪽에서 미리 고름(예: 최근 S·A 정답 팀 5팀, 우리 후보 상위 5팀, 백지 신인 3팀).

### E1. Chartmetric (7일 무료 체험 — Premium 이상이어야 인재 검색·공연 기능이 보일 수 있음)
1. **아티스트 페이지 → 공연(Live/Events) 탭:** 국내 인디 팀(확인용 팀)의 공연이 있나? 몇 건이고 어느 출처(예매처·밴즈인타운 등)로 표시되나? **라인업 역할**(헤드라이너/서포트)은 어떻게 정해지나? → 우리 인디스트릿 기록과 건수 비교(숫자만 메모).
2. **공연장 페이지:** 롤링홀·웨스트브릿지·상상마당 라이브홀·언플러그드 같은 국내 공연장이 있나? **수용 인원**이 있나? **Venue Journey**에서 '체급'은 몇 구간이고 기준(수용 인원 숫자)은? 1·3·5년 전환은 어떻게 보이나?
3. **페스티벌 페이지:** 펜타포트·DMZ 피스트레인·부산록페가 있나? 페스티벌 **순위·점수의 말풍선 정의**는?
4. **아티스트 점수·경력 단계·모멘텀 말풍선:** 2022년 설명(30일 vs 60일)과 2025년 설명(12개월 기울기) 중 지금 화면은 어느 쪽? 단계 구간 숫자는? '이머징'은 어떤 조건?
5. **인재 검색(Talent Search):** 7개 지표의 **정확한 이름**과 등급(색) 기준 말풍선. '트리거 도시'에 서울이 있나?
6. **발굴 필터:** 7일/28일 변화가 어떤 지표의 변화인지, 'HOT'이나 '브레이크아웃' 같은 표시가 있는지와 정의.
7. **점수 이력 그래프로 미니 외부 비교:** 확인용 정답 팀 5팀의 점수·단계 그래프에서 **정답(수상) 날짜 전에 단계가 오르거나 모멘텀이 '폭발'로 바뀌었나?** 우리 첫 신호 날짜와 비교해 누가 먼저였나(날짜만 메모).
8. **빠진 공연 제보:** 제보 화면이 있나? 어떤 정보를 요구하고 승인 절차는?
9. **도시 청취자:** 확인용 팀의 '많이 듣는 도시'에 서울 외 도시가 나오나? 몇 개 도시까지?
10. **신원 매칭:** 이름이 흔한 국내 팀을 검색했을 때 둘로 나뉘나 합쳐지나? 잘못 합쳐진 경우 신고 방법은?

### E2. Viberate (7일 체험, 카드 필요)
1. **가입 화면(onboarding/basic-info):** 어떤 질문(직무·목표·장르)을 받는지 — 우리 앱의 첫 화면 설계에 참고.
2. **아티스트 페이지:** Viberate **포인트·순위**(전체·국가·장르)와 **커리어 건강도** 말풍선 정의. '비슷한 동료' 비교는 누구와 비교하나?
3. **A&R 차트 → HOT 필터:** HOT의 정의(기간·지표). '상위 청취 도시' 필터에 한국 도시가 나오나?
4. **공연 분석(Event Analytics):** 도시를 서울로 두면 어떤 공연이 나오나? 국내 소규모 공연장·인디 공연이 잡히나? 출처 표시는?
5. **공연장·페스티벌 페이지:** 국내 공연장 수용 인원·종류, 페스티벌 '라인업 강도'·'건강 지표'의 말풍선 정의.
6. **알림 설정 화면:** 고를 수 있는 조건 목록(순위 도달·팔로워 증가·급성장)과 기준값 입력 방식 → 우리 알림 설계에 참고.
7. **기여(Contribution):** 국내 공연장·공연을 추가하는 양식에 어떤 칸이 있고, 검수는 얼마나 걸리나 → 우리 오류 제보 흐름 참고.

### E3. Soundcharts (무료 체험 범위 확인 필요)
1. **알림 설정:** 마일스톤 종류와 기준값을 어떻게 정하나?
2. **Soundcharts 점수 말풍선** 정의.
3. **A&R 발굴 → 맞춤 차트:** 국가를 한국으로 두면 어떤 목록이 나오나? **숨김 목록**은 어떻게 쓰나?
4. **한국 라디오 방송국**이 모니터링 목록에 있나?

### E4. Songstats (무료 앱)
1. **알림 설정(프로필 설정 → 알림):** 플랫폼별 고를 수 있는 활동 종류 목록.
2. **아티스트·레이블 추천:** 추천 이유가 어떻게 표시되나?
3. 국내 인디 팀의 플레이리스트·차트 활동이 잡히나(확인용 팀 2~3개)?
