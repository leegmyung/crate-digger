# 처음 온 사람이 무엇을 해야 할지 아는가 — 단순화 개선안 10개 (2026-11-28)

> **계기:** 사용자 의견 — "세세한 기능은 많은데 직관적이지 않은 것 같음".
> **방법:** 앱을 처음 쓰는 A&R 담당자 역할로 흐름을 따라가며 막히는 곳을 적었다.
> - 흐름: 홈 → 발굴 → 팀 페이지(칩 포스트 갱) → 공연장(Club FF) → 알림 → 내 목록 → 차트·검색
> - 환경: 로컬 서버, 1280·375 폭
> - 화면마다 기계로 센 것: 제목·버튼·링크·말풍선·입력 수, 글자 수, 세로 길이
> **범위:** 정렬·간격(레이아웃 작업자 몫)이 아니라 **구조와 흐름**만 다룬다. 이 문서는 **제안**이다. 코드는 고치지 않았고, 사용자가 고른 것부터 만든다.

**핵심 원인 세 가지**
1. **화면이 '질문' 대신 '자료'로 시작한다.** A&R의 질문(오늘 누구를? 왜? 다음엔 뭘?)에 대한 답이 아래쪽에 있다.
2. **같은 정보가 여러 곳에 있다.**
   - 점수·순위·단계는 팀 페이지 안에서 세 번 나온다.
   - '관심/저장 필터/구독'은 홈·발굴·내 목록·알림 네 곳에 흩어져 있다.
   - '갓 데뷔·떠오르는'은 발굴 프리셋과 차트 탭 두 곳에 있다.
3. **안쪽 용어를 그대로 쓴다.** 갈래·정답·백지·선정·중간 정답·맥락 매체·같은 집안·체급·추정·약함·채움 숫자(51/100팀).

## 1. Chartmetric은 같은 문제를 어떻게 푸나 (원리 6개)

출처: [Chartmetric ① 아티스트·발굴·알림](research_2026-11-27_chartmetric_artist.md), [② 공연·공연장](research_2026-11-27_chartmetric_live.md)

1. **빈 첫 화면을 '할 일'로 채운다.** 대시보드는 팔로우한 팀이 없으면 '추천 아티스트' 표와 역할별 **할 일 카드 4장**(페이지로 가기 / 완료로 표시)을 보여 준다. 첫 화면이 '자료 요약'이 아니라 **다음 행동**이다.
2. **점수 1개 + 요약 4칸, 숫자는 한 번만.** 아티스트 개요는 머리 띠(이름·순위·태그) → *Career Snapshot* 4칸(막대 + 쉬운 말 상태) → 변화 타일 순서다. 같은 숫자를 다시 쓰지 않는다.
3. **발굴은 '프리셋 줄 + 한 표 + 빠른 보기'.** A&R 화면은 둥근 프리셋 아이콘 7개 → 히트맵 표 1개다. 줄을 누르면 오른쪽에 빠른 보기가 열린다. 필터는 '필터 추가' 단추 뒤에 숨긴다. 차트(Trending Now)는 탭으로 분리돼 있고 정의 문장이 칩으로 붙는다.
4. **알림은 피드가 아니라 구독.** 리포트 센터는 **빠른 알림 카드 6장**에서 내가 고른 것만 받는다. 만들 때 '조건이 이미 충족되었습니다' 같은 미리보기를 보여 준다. 400건짜리 목록을 먼저 내밀지 않는다.
5. **블록 순서 공식이 화면마다 같다.** 머리 띠 → 숫자 상자 한 줄(숫자 아래 기간 꼬리표) → 분포 막대 → 큰 표 → 그림. 💡 요약 문장 2~3개가 표 위에 붙는다.
6. **주요 동작은 머리 오른쪽 아이콘 4개로 모은다.** 알림·비교·새로고침·다운로드다. 긴 화면은 스크롤하면 머리가 얇은 띠로 붙는다.
