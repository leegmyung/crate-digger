## 1. 학습 모델 vs 손 공식 (기준일 하나 빼고 학습 → 뺀 기준일 채점)

기준일 6개(2023-01-01, 2023-07-01, 2024-01-01, 2024-07-01, 2025-01-01, 2025-07-01), 관찰 24개월. 후보군·특징·지표는 `score_tune`과 같다(앱·[점수 교차 검증](score_tuning.md)·[방법론](methods.md)과 같은 계산). 6개 기준일을 합치면 후보 25,059행, 정답 109행.

- **v2 (고정)**: 지금 기본 손 공식(`lab_sql.DEFAULTS`)을 그대로 채점. ⚠️ v2 가중치는 기준일 6개 **전부**를 보고 고른 값이라 이 열은 '시험 문제를 미리 본' 점수다(공정한 비교 상대가 아니라 참고용). 지금 데이터로 6개 전부를 보고 다시 고르면 `branch 0 · stage 1 · peer 1 · dmz 0 · gigs 0 · outlets 1 · recent 1 · venues 1 · winner 0 · context 0.25 · collab 0`(평균 0.897)이고 v2는 0.866로 거의 최상위다.

- **로지스틱 회귀**: 같은 특징 10개(v2와 같은 변환)에 계수를 데이터로 맞춘 모델. numpy 경사하강 + L2 벌점(계수가 너무 커지지 않게 누름), 정답 등급(S3·A2·B1)을 표본 가중치로 쓰고 정답 쪽 총 무게를 비정답 쪽과 같게 맞춤. 특징 표준화(평균 0·표준편차 1)와 L2 강도 고르기는 **학습 기준일 5개로만** 했다 — L2는 그 5개 안에서 다시 하나 빼기로 골랐다(뺀 기준일은 끝까지 안 봄).

### 1-2. 계수 (기준일 6개 전체로 학습, L2 0.01)

계수 = 표준화된 특징이 1(표준편차 하나)만큼 클 때 정답 가능성(로그 오즈)이 얼마나 오르는지. '기준일별 범위'는 하나 빼고 학습한 6번의 계수 최소~최대이고, 부호가 바뀌면 그 특징의 방향은 믿기 어렵다. '비중'은 |계수|를 합이 100%가 되게 나눈 것이고, v2 비중은 v2 가중치에 특징 표준편차를 곱해 같은 단위로 바꾼 것. DMZ는 '제외' 출처라 특징값이 늘 0이다.

### 1-3. 해석

1. **공정 비교 결과**: 학습 모델과 공정한 손 공식은 **사실상 같다**(차이 -0.008, 95% 구간 -0.023~+0.005가 0을 지남). 학습 모델이 손 공식보다 확실히 낫다고 말할 근거가 없다.
2. **지금 데이터에서는 v2 가중치가 최선이 아니다**: v2 고정(0.866)이 기준일마다 다시 고른 손 공식(교차 0.889)보다 **0.023** 낮다 — v2는 이전 데이터로 고른 가중치라, 데이터가 바뀐 뒤엔 새로 고른 가중치가 안 본 시점에서도 더 잘 맞는다(→ [점수 재검토](data/score_review.json) 변경 제안). 다만 상위 50 적중은 따로 본다(1절 표). 여기에 더해 신인 판정을 모든 팀에 같은 기준으로 맞추면 v2 AUC가 0.019 더 내려간다(1절 '같은 기준 판').
3. **과적합 위험**: 6개 기준일 정답이 109행(같은 팀이 여러 기준일에 다시 셈)이고 특징이 10개라 특징 하나당 정답이 10개도 안 된다. 기준일마다 고른 L2 강도도 0.001~0.1로 크게 흔들렸다. 손 공식 교차 검증에서도 뺀 기준일마다 골라지는 가중치가 달랐다 (→ [점수 교차 검증](score_tuning.md)). 지금 표본으로는 어느 방법이든 '정확한 가중치'를 찾기 어렵다.
4. **계수 부호와 상식**: 늘 플러스인 특징 — 선정 최고 단계, ln(1+공연장 수), ln(1+최근 180일 신호), min(발굴 매거진, 3), 선정 팀과 같은 무대 → 상식과 맞다(선정·공연장 다양성·매체 소개·최근 활동이 많을수록 정답 가능성↑). 부호가 기준일마다 바뀐 특징 — 갈래 수 − 1, 수상 팀과 같은 무대, min(맥락 매거진, 3), ln(1+1년 공연 일수) → 방향을 믿기 어렵다. '1년 공연 일수'가 마이너스로 나오는 건 '공연장 수'와 겹치기 때문으로 보인다(공연장 수가 같다면 같은 곳에 자주 서는 것은 덜 중요하다는 뜻). '갈래 수'가 0 근처인 것도 선정·매체·공연장 특징이 이미 갈래 정보를 담고 있어서다.
5. **손 공식과 비중이 크게 다른 특징**(10%p 이상): ln(1+최근 180일 신호) — 로지스틱 21% vs v2 0%; 수상 팀과 같은 무대 — 로지스틱 2% vs v2 27%. 로지스틱 쪽이 무조건 맞다는 뜻은 아니지만, 다음 가중치 점검 때 볼 곳이다.

### 1-4. 권고 (바꾸지 않고 제안만)

- **기본 점수는 손 공식(v2)을 유지**한다. 학습 모델이 공정 비교에서 이기지 못했고, 손 공식은 발굴 담당자가 '왜 위에 있나'를 바로 읽을 수 있다.
- 학습 모델은 **가중치 점검 도구**로 쓴다: 정답이 쌓일 때마다 이 스크립트를 돌려 계수 부호가 뒤집히거나 비중이 크게 벌어지는 특징을 찾는다.
- 앱·문서에서 v2 성능을 말할 때는 고를 때 안 본 시점 기준(0.89 안팎)을 함께 적는 것을 제안한다.
- 최근 활동(최근 180일 신호)은 로지스틱에서 꾸준히 플러스이고, 지금 데이터로 전체를 다시 고른 손 공식에도 가중치 1로 들어간다 → 다음 `score_tune` 때 후보로 다시 볼 것.
- 다시 비교할 때: 정답이 지금의 2~3배(기준일 합산 200행 이상)가 되거나, 검증 대기 출처(인스타·발매)가 첫 정답 시즌을 지난 뒤.
