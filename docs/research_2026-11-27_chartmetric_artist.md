## 0. 한눈에 보는 결론

**핵심 발견 7개**

1. **점수 체계는 '점수 1개 + 4칸 요약 카드'.** 아티스트 첫 화면의 *Career Snapshot* 카드에 **경력 단계 · 최근 모멘텀 · 네트워크 강도 · 소셜 참여도** 4개가 각각 '왼쪽 끝~오른쪽 끝' 막대(게이지)로 나옵니다. 말풍선 정의: 경력 단계 = **지난 1년 평균** Chartmetric 점수(공개 글의 '중앙값'과 다름), 모멘텀 = **지난 1년 점수 추세, 최근에 무게**. 구간 숫자(몇 점부터 '주류'인지)는 화면 어디에도 없습니다.
2. **모든 숫자를 '비슷한 크기의 동료'와 비교합니다.** 스포티파이 화면은 "비슷한 팔로워 수를 가진 4,451 아티스트들과 비교"라며 최소·중앙값·최대 막대 위에 내 위치와 **'탁월함·훌륭함·평균·평균 이하'** 등급을 붙이고, 참여율 카드도 "6,627명의 아티스트 · 30.2만–50.3만 팔로워" 안에서의 위치를 보여 줍니다. 마일스톤 별점도 **경력 단계에 맞게 조정**합니다. → 우리 점수에도 그대로 들일 수 있는 장치입니다(크기가 다른 팀끼리 날것으로 비교하지 않기).
3. **발굴 도구 'Rising Index'는 8칸짜리 1~10점 색 지도(히트맵).** 화면 설명은 "7가지 지표를 1에서 10까지"인데 실제 칸은 8개: 성장 지속도(3개월)·동기화된 성장(1달)·사용자 참여도·사용자 큐레이션·에디토리얼 큐레이션(각 1달)·반응 지역(최근)·국제적 성과·청취자 집중도(현재). 대상 44.8만 팀 중 **칸마다 값이 있는 팀 수가 크게 다름**(예: 사용자 참여도 1.8만, 청취자 집중도 3.4만 팀만 값 있음 — 나머지는 N/A 회색). 칸별 정의 말풍선은 화면에 없었습니다.
4. **필터에 '첫 발매 < N개월'과 '협업' 필터가 있습니다.** 첫 발매 6~120개월, 최신 발매, 최근/다음 공연(1주~1년), 활동 중지, AI 아티스트, **'뛰어난 협업' 켜짐/꺼짐**, 경력 단계·모멘텀·네트워크 강도. 우리 신인 기준(첫 발매 3년)과 협업 신호(w_collab)가 그들에게도 **필터**로 있다는 뜻입니다(점수가 아니라).
5. **알림은 '6종 빠른 알림 + 단계별 만들기 + 미리보기'.** 리포트 센터: 지표 알림(기준값 초과)·% 변화 알림·플레이리스트 알림·차트 알림·바이럴 동영상 알림·**공연장 알림(아티스트가 그 공연장에서 공연할 때, 상위 요금제)**, 그리고 **"저장한 프리셋 필터에 새 아티스트가 맞으면 알림"**. 만들기 창은 대상 선택 → 항목 → 조건 → 받는 방법 → 확인 5단계이고, 저장 전에 "조건이 이미 충족되었습니다" 같은 **알림 예측**을 보여 줍니다.
6. **'사건 전후 비교(이벤트 분석기)'가 아티스트 화면에 기본으로 있습니다.** 발매·공연 같은 사건마다 당일·7·14·21·28일 뒤 지표 변화율 표, 공연 탭 위에는 "성장은 일반적으로 이벤트 후 약 14일에 최고점, 4개 이벤트 평균 성장률 +18.37%" 같은 요약 문장. 그리고 "11월 8일 월간 청취자가 평소 성장률 대비 3.3천% 상승" 같은 **이상치 자동 문장('주목할 만한 통찰력')**.
7. **한국 인디 커버리지: 팀은 다 있지만 '인디의 핵심 신호'가 비어 있습니다.** 정답 5팀 모두 검색됨. 그러나 ① 5팀 모두 장르가 **'Korean R&B/Soul'·'Krnb'로 잘못 붙음**(밴드인데도), 한로로는 마일스톤에 '세계 hip-hop/rap 상위 1천'으로 나옴. ② 공연 기록은 **펜타포트·서울재즈페스티벌·원더리벳 같은 큰 페스티벌뿐**, 클럽·소극장 공연은 0건(우리 데이터엔 피치트럭하이재커스 공연 11건·공연장 5곳). ③ 가장 작은 팀(피치트럭하이재커스)은 스포티파이만 연결, 경력 단계 '발전 중', 순위 41만 위권, Rising Index에도 없음. → **작고 이른 단계의 국내 인디는 우리가 확실히 앞섭니다.** 반대로 멜론 팬 수·멜론/한터/써클 차트는 그들도 갖고 있습니다.

**우리가 바로 만들 것 5개** (자세한 표는 6절)

1. **'비슷한 체급과 비교' 칸** — 후보 목록·팀 화면의 숫자 옆에 "같은 단계·같은 공연장 체급 팀 N팀 중 상위 몇 %"와 4단계 등급(탁월·좋음·보통·아래). 우리 데이터로 지금 가능.
2. **'사건 전후' 표** — 선정·큰 공연장 첫 출연·매거진 소개 같은 사건 전후 28일 동안 그 팀의 신호(공연 수·언급 수·인스타 팔로워)가 어떻게 변했나. 알림 근거로도 씀.
3. **알림 만들기 미리보기 + '저장한 필터에 새 팀이 들어오면 알림'** — 지금 alerts.json의 8종을 그대로 두고, 사용자가 후보 목록 필터(장르·첫 발매·지역)를 저장하면 새로 맞는 팀을 주간 알림에 넣기.
4. **'Career Snapshot'식 4칸 요약 카드** — 팀 화면 맨 위에 발굴 단계·최근 활동·갈래 수·씬 연결(같은 무대 수상 팀)을 막대 4개로. 정의를 말풍선으로.
5. **신호별 '값 있는 팀 수' 표시** — 점수 칸마다 몇 팀이 그 값을 가졌는지(Rising Index의 'N/A'처럼) 보여 줘서 빈칸을 0점으로 오해하지 않게.

## 2. 화면별 레이아웃

### 2-1. 대시보드 (첫 화면)
- 위→아래: ① 가운데 정렬 탭 2개 **'내 목록' / '내 인사이트'**(인사이트에 새 소식 점) → ② 왼쪽 위 드롭다운 '아티스트'(트랙·앨범 등으로 바꿈) → ③ 큰 흰 카드 **'추천 아티스트'**("아티스트를 팔로우하여 대시보드에서 추적을 시작하세요") 표: 칸 = 아티스트(사진·국기·이름) · 팔로우 버튼 · Chartmetric 팔로워 · 스포티파이 팔로워 · 월간 리스너. 표 위에 '표시 10/20/50/100', 쪽 번호, 오른쪽 세로 '모든 컬럼'(칸 고르기) → ④ 환영 영상 · **역할별 할 일 카드 4개**(분석 보기·쇼트리스트 만들기·이메일 리포트 만들기·아티스트 비교, 각 '페이지로 가기 / 완료로 표시') → ⑤ 요금제 광고.
- 팔로우한 팀이 없으면 '추천'(우리 계정에선 K-팝 대형 팀)이 채워짐. **빈 첫 화면을 '해야 할 일'로 채우는** 방식.
- 색·밀도: 흰 배경, 진한 청록 왼쪽 메뉴, 버튼도 청록. 표 줄 간격 넓음(한 화면 8~9줄). 숫자는 '1.2천·9107.7만'처럼 한국식 단위.

### 2-2. 아티스트 상세 — 개요 탭 (위→아래)
1. **머리 띠(배너):** 흐린 사진 배경 위 큰 원형 사진 · 이름(한글/영문) · 재생·추가·편집 버튼 · `순위 9,277th · 국기 KR · 성별·솔로/그룹 · 레이블` · 장르/분위기 태그 칩(Korean R&B/Soul · Emotional · Summer · 더보기). 오른쪽 위 아이콘 4개: **사용자 지정 알림(종) · 아티스트 비교 · 데이터 다시 불러오기 · 다운로드**. 오른쪽에 '원시트(onesheet, 홍보용 한 장 요약)' 광고 카드.
2. 왼쪽 고정 칸: 작은 사진·이름·장르 · 팔로우 버튼 · 숏리스트 추가 · 알림 · 연결된 플랫폼 아이콘(+27개 링크) · 탭 목록.
3. 처음 쓰는 사람용 '0/4 단계 완료' 카드(팔로우·숏리스트·맞춤 알림·Flow에게 묻기).
4. **Career Snapshot:** 가로로 4칸. 칸마다 제목(말풍선 ⓘ) → 큰 글씨 현재 값(예: '주류', '안정') → 초록 막대 → 막대 아래 양끝 이름(예: 발전 중 ↔ 전설적, 상승세 둔화 ↔ 폭발적인 성장, 활동 중 ↔ 영향력 있는).
5. **지표 변화 타일 줄:** 7D / 30D / 총계 / '이전 7일 대비' / 사용자 지정 전환. 플랫폼 로고 + 지표 이름 + 큰 '+4.8천' + 초록 '↑1.2%' + 작은 회색 현재 값(40.6만). 13개(스포티파이 팔로워·월간 청취자·인기도·플레이리스트 도달, 유튜브 구독자·조회수, 인스타 팔로워, 틱톡 팔로워·좋아요, 디저, 샤잠, 판도라, 라디오 재생).
6. **마일스톤 3장**(최근 업적 문장 + 날짜 + '모든 마일스톤 보기') + **Flow 질문 버튼 4개**("이 아티스트의 주요 스트리밍 트렌드는?" 등).

8. **유튜브 국가·도시 트렌드:** 상위 국가 3 · 상위 도시 3 · 변화율 상위 국가/도시(1개월·3개월) — 4칸 목록.
9. **Chartmetric 아티스트 랭킹(지난 30일):** 전체 순위 + 국가 순위 + 장르별·지역×장르별 순위 칩 수십 개(#171 대한민국, #25 Krnb, #7 Korean Ambient …).
