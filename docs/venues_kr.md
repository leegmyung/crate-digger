- 마스터 목록 **257곳** — 운영 206 · 확인 필요 47 · 휴업 0 · 폐업 4.

## 5. 수집 후보 출처 (공백을 채우는 순서 제안)

1. **인디고 과거 공연 되짚기** — 공백 공연장 중 11곳은 인디고에 지난 공연 기록이 있습니다(공연장 페이지 '지난 공연' 수). 이미 쓰는 출처이고 robots가 허용하므로 가장 싼 길입니다([지방 출처 조사](research_2026-11-27_regional_gigs.md) 후보 ①).
2. **지방 공연장 인스타그램** — 공백 공연장 중 20곳은 공식 계정을 압니다: @moomonk1995(부산), @bhoso_official(대전), @nogada_pub(부산), @namon_jeju(서귀포), @suwon_musiccamp(수원), @the_vine_hall(전주), @2d_hall(제주), @the4zonelive(광주), @livepub_tarock(대구), @4dcosmosmusiclab(대구), @wav3_gwangan(부산), @musiclab_busan(부산), @yaman_joint_official(부산), @belpos_official(부산), @nurirock(세종), @vinta_suwon(수원), @dinggingfriends(수원), @chord_space(인천), @portrock_incheon(인천), @sidekick_production(창원). `config/insta_accounts.json`에 공연장 계정으로 넣으면 기존 `collect_insta.py`로 라인업 글을 받습니다(역할은 '검증 대기'로 시작).
3. **KOPIS 공연예술통합전산망 오픈 API** — 공연시설 목록(`/openApi/restful/prfplc`, 시·도·구군 코드로 거름)과 공연 목록(장르 '대중음악')이 있습니다. 예매처를 거친 유료 공연은 지역과 상관없이 잡혀 광주·대전·전주·제주 같은 빈 곳을 채울 수 있습니다. **인증키가 필요합니다 — 사용자께 `KOPIS_API_KEY` 발급을 요청합니다**(무료, 사용자 계정으로 신청 → `.env`).
4. **라랄라온(2026 소규모 대중음악 공연 활성화 지원, 한국음악레이블산업협회·문체부)** — 전국 소공연장 23곳 라인업 공지에 공연장·날짜·팀이 함께 나옵니다. 한 해 1번 aside로 읽기.
