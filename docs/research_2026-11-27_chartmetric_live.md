# Chartmetric 안쪽 ② — 공연·공연장·도시·페스티벌 (로그인 화면 관찰)

_2026-11-27 · 무료 체험 계정으로 화면을 직접 보고 적은 기록. 화면 구성·메뉴·지표 정의·설명 문구만 메모했고, 데이터를 내려받거나(내려받기 버튼 안 누름) 우리 데이터에 섞지 않았으며, 어떤 양식도 제출하지 않았습니다. 숫자 예시는 공연장·팀 1~2개만 적습니다._

## 0. 한눈에 보는 결론

**핵심 발견 7개**

1. **공연 메뉴는 3개 + 아티스트 탭 1개.** 왼쪽 메뉴 '탐색' 묶음의 **위치(도시·국가) · 공연장 · 라이브 이벤트**, 그리고 아티스트 화면의 **라이브 이벤트 탭**. 화면마다 '위쪽 요약 숫자 상자 → 분포 막대 → 큰 표 → 그림(지도·호·꺾은선)' 순서가 거의 같습니다.
2. **출처는 해외 공연 사이트뿐.** 공연 행마다 **JamBase · Songkick · SeatGeek · Ticketmaster** 아이콘이 붙고, 도시 화면 그래프 말풍선도 "이 데이터는 Songkick에서 가져옵니다". 국내 예매처·인디스트릿·공연장 인스타는 없습니다.
3. **한국 공연은 2,246건뿐이고 대부분 내한·대형 공연.** 전 세계 694만 건 중 한국 2,246건(서울 1,978 · 부산 103 · 인천 56 · 고양 41 · 대구 31), 그중 페스티벌 199건. 같은 공연장으로 비교하면 우리 기록이 몇 배 촘촘합니다(무신사 개러지 28건 vs 우리 161일, 롤링홀 70건 vs 우리 118일, 부산 103건 vs 우리 495일).
4. **한국 공연장 559곳은 있지만 갈라지고·비고·틀립니다.** 상상마당 홍대가 5개, 웨스트브릿지가 3개 항목으로 나뉘었고, 홍대 클럽 대부분 '최근 12개월 공연 0회'. **한글 검색은 0건**(영어 이름으로만 찾힘). 수용 인원은 출처 표시 없이 롤링홀 250(우리 확인 450), 프리즘홀 4,000.
5. **Venue Journey(공연장 사다리)는 한국 공연장에선 '해외 투어의 정류장'으로만 보입니다.** 롤링홀 '전에 선 곳' 20곳·'뒤에 간 곳' 20곳이 **전부 해외 공연장**(조조 마린 스타디움, 하우스 오브 블루스 …). 국내 인디 팀의 '클럽 → 라이브홀' 사다리는 그들 데이터로 안 그려집니다 — 우리가 [공연장 사다리](venue_ladder.md)로 이미 그린 것이 바로 그 빈칸입니다.
6. **'주목도' 점수 정의를 찾았습니다(공연장 표의 말풍선).** "0~100. 최근 12개월 **공연일이 많을수록**, **더 높은 순위의 헤드라이너**가 많을수록, **수용 인원이 클수록** 높아짐. 100이 상한(매일 공연·모든 공연이 최상위 아티스트·수용 인원 10만 기준)." 페스티벌에는 **'순위·점수'가 화면에 없었고**(공개 소개 페이지 주장과 다름), 대신 '신규 아티스트 비율'·'페스티벌 빌 순서(포스터 순서)'가 있습니다.
7. **공연을 '반응'과 잇는 칸이 곳곳에 있습니다.** 공연장 공연 표의 **'영향' = 공연 전후 28일 스포티파이 변화(%) + 작은 꺾은선**, 아티스트 공연 탭 위의 요약 문장("성장은 일반적으로 이벤트 후 약 14일에 최고점 / 109개 이벤트 평균 +1.72%"), **라이브 쇼 트렌드**(분기별 공연 수 막대 + 평균 수용 인원 꺾은선, "수용 인원 성장률 −37% = 5년 전반 대비 후반").

**우리가 바로 만들 것 5개** (자세한 표는 6절)

1. **공연장 목록에 '지도·표 전환 + 체급 막대 필터 + 카드 속 월별 막대'** — `venues_kr.json`(도시)·`venue_capacity.json`(체급)·`venue_profiles`(월별)로 지금 가능.
2. **공연장 상세에 'Venue Journey 호 그림'(가로축 = 체급 S·M·L·XL·모름)** — 앱에 이미 있는 '전후 공연장 흐름' 표를 그림으로. 그들과 달리 **국내 팀의 실제 사다리**가 보입니다.
3. **팀 화면에 '공연 기록' 블록** — 요약 숫자(총 공연·공연장 수·도시 수·최다 공연 도시) + 분기별 공연 수 막대·평균 체급 꺾은선 + 자주 선 공연장 + **함께 선 팀 표(같이 선 횟수·마지막으로 같이 선 공연)** + 공연 표에 출처 칸.
4. **도시 화면(서울·부산·대구 …)** — 요약 숫자 5개(공연장·공연 날짜·최근 1년 공연 팀·첫 무대 팀·나중 정답 팀) + '이 도시에서 뜨는 후보' 카드 + 월별 공연 막대 + 대표 공연장 + 지방 → 서울 흐름. `city_profiles.py` 결과로 지금 가능.
5. **'주목도' 대신 '발굴 주목도'** — 공연장 정렬 기본값을 "최근 12개월 공연일 × 그 공연장 첫 출연 신인 비율 × 나중 정답 팀 비율"로(그들은 헤드라이너 인기·수용 인원으로 매김 → 큰 곳이 위로, 우리는 신인이 처음 서는 곳이 위로). 계산식은 화면 정렬용이고 후보 점수엔 넣지 않음.

## 1. 메뉴·화면 지도 — 어디서 무엇을 볼 수 있나

왼쪽 세로 메뉴(아이콘만, 마우스를 올리면 이름), 위에서 아래로:

| 묶음 | 메뉴 (주소) | 공연 관련 |
|---|---|---|
| 대시보드 | 대시보드 `/dashboard` | |
| 라이브러리 | 아티스트 · 트랙 · 앨범 · 레이블 | 아티스트 화면 → **라이브 이벤트 탭** `/artist/<번호>/live-events` |
| 차트 · 마케팅 · 도구 | 차트 · 재생 목록 · 인플루언서 · 브랜드 · 큐레이터 · 비교 · 최종 후보 · 리포트 | 리포트 센터에 '공연장 알림'(상위 요금제, ① 문서) |
| 탐색 | A&R · **위치** `/locations` · **공연장** `/venues` · **라이브 이벤트** `/live-events` · 장르 · Airplay · 트렌딩 사운드 | ✅ 공연 기능 3개 |

화면끼리 연결: 라이브 이벤트 표의 이벤트 이름 → 페스티벌 화면 `/festival/<번호>`, 도시 이름 → 도시 화면 `/city/<번호>`, 국가 → `/country/KR`, 공연장 → `/venue/<번호>`, 아티스트 → 아티스트 화면. **모든 이름이 링크**라 표에서 표로 계속 건너갈 수 있습니다.

공통 틀: 위쪽 띠(전체 검색 ⌘K · 업그레이드 · 밝기 · 언어 · 공지 · 도움말 · 계정), 오른쪽 아래 'Flow에 질문하기'(AI 질문) 버튼이 모든 화면에 떠 있음. 표는 모두 '표시: 10/20/50/100' · 쪽 넘김 · 오른쪽 끝 세로 글씨 **'모든 컬럼'**(칸 고르기·왼쪽 고정) · 내려받기 아이콘.

## 2. 화면별 레이아웃

### 2-1. 공연장 목록 `/venues`

```
┌ 공연장  529,138개 ───────── [ 공연장 검색 ............ 🔍 ] [📍지도|☰표] ┐
│ (국가▾)(도시▾)(수용 인원 ▁▃▅ 전체▾)(유형▾)(장르▾)(유사 공연장 추가▾) ☑지난 ☐예정 모두 초기화 │
│ [국가: 대한민국 ×]  ← 고른 필터가 칩으로                                │
├──────────────┬──────────────────────────────────────────────┤
│ 정렬: 주목도▾ 1–20/559 │                                              │
│ ┌ 🎫 The O2        │            지도 (숫자 원 = 공연장 묶음)          │
│ │ 아레나·수용 20,000│      "359,422개 중 1,884개 표시 · 보기 초기화"      │
│ │ 👤👤👤 공연 180회·12개월 ▁▂▃▅▃▆ │                                     │
│ └──────────────┘                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- **필터 6개 + 체크 2개.** 수용 인원은 **막대그래프 필터**: 6구간 막대(<300 · 300–1K · 1K–3K · 3K–5K · 5K–20K · 20K+, 막대마다 공연장 수)를 누르거나 손잡이를 끌고, 최소·최대 숫자 직접 입력. 설명 문구 "수용 인원별 공연장 수 막대를 클릭하거나 핸들을 드래그하세요". 유형 7가지(바/클럽 · 페스티벌 · 극장 · 콘서트홀 · 아레나 · 스타디움 · 앰피시어터, 각각 개수). 국가는 공연장 많은 순(미국·일본·영국·중국·독일·프랑스·**대한민국** …), 한국을 고르면 주소가 `?countryCode=KR`, 도시 목록이 "Seoul 419개 공연장 / Busan 39 / Daegu 18 / Gwangju 9 / Daejeon 7 / Incheon 6 / …".
- **지도 보기(기본):** 왼쪽 1/3 카드 목록 + 오른쪽 2/3 지도. 카드 = 유형 아이콘 · 이름(굵게) · '유형 · 수용 인원' · 대표 아티스트 얼굴 3개 · '공연 N회 · 12개월' · **오른쪽 끝 월별 공연 수 작은 막대 12개(청록)**. 정렬: 주목도(기본) · 수용 인원 많은/적은 순 · 최근 공연 · 공연 많은 순 · 이름.
- **카드를 누르면 오른쪽에 미리보기 패널:** 유형 · 이름 · 도시·국가 · 수용 인원 · **'활동 중'** · **'대한민국 수용 인원 N위'** · 출연 아티스트 수와 상위 3팀 · **장르 구성 상위 4개(%)** · '공연장 열기' 버튼. (목록을 벗어나지 않고 훑어보기 → 필요할 때만 상세로)
- **표 보기:** 칸 = 공연장(아이콘·사진) · 위치(도시 + 국기 + 국가 코드) · 유형 · 수용 인원 · **공연(12개월)** · **주목도** · 최근 공연(날짜 + 공연 이름 작은 글씨) · 최고 인기 아티스트. 칸 머리의 ⓘ 말풍선은 3절.
- **색·밀도:** 흰 카드 + 연회색 바탕, 강조색 청록 하나. 선택된 필터는 노란 테두리. 카드 한 장 4줄, 표 한 줄 높이 넉넉(2줄 칸 허용).

### 2-2. 공연장 상세 `/venue/<번호>` — 무신사 개러지·롤링홀

위→아래:

1. **머리 띠(공연장 사진을 흐리게 깐 회색 띠):** 왼쪽 큰 아이콘 카드 · 이름(흰 큰 글씨) · '📍 서울, 대한민국'. 오른쪽 위 '🔔 사용자 지정 알림' 버튼, 그 아래 반투명 **'공연장 상세 정보' 상자**: 최근 공연(날짜·공연 이름) · 최고 인기 아티스트 · '이곳의 공연 보기'. (상세 화면엔 **수용 인원이 안 보이고** 목록 미리보기에만 있음)
2. **아티스트 장르 분포:** 'N개 장르' 배지 · '주요 장르 시그널' · **가로 누적 막대 1줄**(상위 5개 장르 색 + 기타 회색) + 범례(%) · 오른쪽 '상위 5개 장르가 63.9%' · '전체 보기' 펴면 순위표.
3. **아티스트 요약:** "이 공연장에서 공연한 모든 아티스트(공연 횟수순)." 오른쪽 큰 숫자 2개(아티스트 · 공연). 칸 = 아티스트(사진) · 차트메트릭 랭킹 · 장르 태그 3개 · 공연 수 · 첫 공연 · 최근 공연.
4. **이벤트 표:** 검색 · 과거/예정 · 콘서트&페스티벌 · 내려받기. 칸 = 이벤트(이름 + '콘서트/축제' 배지 + 바깥 링크 ↗) · 아티스트(+N) · 날짜(시간) · 가격 · **영향**(스포티파이 아이콘 · 공연일 점선이 있는 작은 꺾은선 · ↑초록/↓빨강 %) · **출처**(JB · SK · SeatGeek · t 아이콘, 있는 곳만 진하게).
5. **Venue Journey:** 설명 문구 원문 — "아티스트들의 커리어가 이 공연장을 어떻게 거쳐가는지 — 모든 공연장은 하나의 수용 인원 활주로 위에 놓입니다. 파란 아크는 이곳에서 공연하기 전에 섰던 공연장, 주황 아크는 그 후에 나아간 공연장입니다. 아크가 멀리 뻗을수록 더 큰 변화입니다."
   - 가로축 = **수용 인원 로그 눈금(100 · 500 · 2.5K · 10K · 50K · 250K)**, 오른쪽 끝에 '이 공연장' 아이콘. 공연장마다 번호 원이 축 위에 찍히고 '이 공연장'과 아치로 연결(굵기 = 팀 수로 보임). 기간 고르기 **1년 · 2년 · 3년(기본) · 5년 · 10년**.
   - 아래 두 단 목록: **'이전에 공연한 곳'(파란 번호)** · **'이후에 이동한 곳'(주황 번호)**, 각 20곳(이름 + 수용 인원, 큰 순).
   - 실제 모습: 무신사 개러지 '전에 선 곳' 1~5위가 체펠린펠트(20만)·그랜트 파크(10만) 같은 해외 대형 페스티벌, 롤링홀은 앞뒤 40곳 모두 해외 공연장 — **내한 해외 팀의 투어 경로**만 보입니다.

### 2-3. 라이브 이벤트 `/live-events`

1. **이벤트 지도(위 카드):** 제목 + "스크롤로 확대, 드래그로 이동" · 도시 검색 · [글로벌|미국] · [● 모든 이벤트 | ● 콘서트(청록) | ● 페스티벌(주황)] · [전체 기간 | ● 지금 진행 중 | 날짜 선택] · 되돌리기. 지도 왼쪽 위 큰 숫자 2개(**6,944,123 지난 이벤트 · 14,156 전 세계 개최지**), 오른쪽 아래 범례 "버블 크기 = 이벤트 수". 한국은 점 몇 개뿐.

### 6-3. 화면 디자인으로 가져올 것 (UI/UX)

- **블록 순서 공식:** 머리 띠(이름·위치·요약 상자) → **숫자 상자 한 줄**(아이콘 + 작은 회색 이름 + 큰 숫자 + 아주 작은 기간 글씨 '12개월'·'2년') → **분포 누적 막대** → 큰 표 → 그림. 우리 공연장 상세·도시 화면도 이 순서로 맞추면 화면끼리 익숙해집니다.
- **숫자 아래 기간 꼬리표:** "추적된 이벤트 271 / 2년", "공연 180회 · 12개월"처럼 숫자마다 기간을 작게 붙임 — 우리 숫자(공연 날짜·첫 출연 팀)에도 '기준일까지·최근 1년'을 붙이면 오해가 줄어듭니다.
- **💡 요약 알약:** 표 위에 한 문장짜리 발견 2~3개(그들: "성장은 이벤트 후 약 14일에 최고점"). 우리: "이 공연장에 처음 선 팀 중 1년 안에 L 체급으로 간 팀 N%", "정답 팀 N팀이 여기서 먼저 섰음(중앙값 N개월 전)".
- **모든 이름은 링크:** 팀 → 팀 화면, 공연장 → 공연장 상세, 도시 → 도시 화면. 표 안 칩(공연장 칩·도시 칩)도 누를 수 있게.
- **필터 칩 + '모두 초기화':** 고른 필터를 칩으로 보여 주고 ×로 지움. 체급 필터는 막대그래프로(숫자를 모르는 사람도 '작은 곳이 많다'를 바로 봄).
- **카드 속 작은 막대 12개:** 목록 카드 오른쪽 끝 월별 공연 막대 — 활동 중인지 한눈에. 우리 앱의 '월별 공연 날짜' 블록을 작게 줄여 목록에도.
- **'모든 컬럼'과 행 수 고르기:** 표마다 칸 고르기·왼쪽 고정, 10/20/50/100.
- **색:** 강조 청록 하나 + 의미색 2개(전 = 파랑, 뒤 = 주황 / 상승 = 초록, 하락 = 빨강). 콘서트 청록·페스티벌 주황처럼 **종류를 색으로 고정**.
- **스크롤하면 머리가 얇은 띠로 줄어 붙음:** 긴 화면에서도 지금 어느 공연장·페스티벌인지 잃지 않음.

### 6-4. 그들의 약점을 피하기

- **갈라짐 금지:** 연결표와 '묶지 않음' 근거(예: 언플러그드 두 곳은 주소가 달라 따로)를 공연장 상세에 '같은 곳으로 묶은 표기'로 보여 주고, 오류 제보는 기존 이슈 양식으로.
- **수용 인원엔 출처·확인일·확실도 함께:** 롤링홀 250(그들) vs 450(우리 확인) 같은 차이를 사용자가 직접 확인할 수 있게 링크 표시.
- **한글·영문 별칭 모두 검색.**
- **작은 표본 순위 숨기기:** 그들 서울 유튜브 순위처럼 조회수 몇백으로 1위가 되는 일을 막기 위해, 도시·공연장 순위는 최소 표본(예: 공연 날짜 5일 이상) 아래면 '표본 적음'으로 흐리게.
- **'체급 상승'은 점수가 아니라 화면 정보:** 교차 검증에서 효과가 없었음([venue_ladder.md 3절](venue_ladder.md)) — '참고' 표시 유지. 발굴 주목도도 정렬용일 뿐 후보 점수에 넣지 않음(넣으려면 별도 백테스트 + 사용자 확인).
