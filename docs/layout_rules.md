# 표·목록·카드 정렬 규칙 (2026-11-28)

> 바탕: [design_spec_from_chartmetric.md](design_spec_from_chartmetric.md) 2·3·4절(숫자는 표 안 14px, 표는 '촘촘/편하게' 두 밀도, 꼬리표는 네모).
> 공통 모양은 **`docs/app/css/tables.css` 한 곳**에 있고 `style.css` 맨 위에서 `@import` 로 먼저 읽힙니다. 화면별 CSS는 그 위에 칸 너비만 덧칠합니다.
> 검사: `tests/test_layout_rules.py`, `tests/js/entity_cell.test.mjs`.

## 1. 숫자·날짜

| 규칙 | 어떻게 |
|---|---|
| 숫자는 **오른쪽** 정렬, 고정 폭 숫자 | 칸에 `class="num"` → 오른쪽 + `font-variant-numeric: tabular-nums` + 줄바꿈 없음 |
| **머리글 정렬 = 내용 정렬** | 숫자 칸이면 `<th class="num">`도 같이. 가운데 칸이면 둘 다 `center` |
| 날짜 | 왼쪽 정렬, 표 전체에 tabular-nums 가 걸려 있어 자릿수가 줄마다 맞음. 날짜 칸은 `col-fit` |
| 순위 변동(▲3) | 순위 숫자 뒤에 붙이지 않고 **자기 칸**(또는 순위 아래 줄)에 |

## 2. 이름 칸 — `.cell-entity`

```
[사진 28px] 이름 (넘치면 말줄임…)          [▶][⇄]
            아래 줄: 배지 · 장르 · 예정 1일
```

- 만들 때는 `components/entity_cell.js`의 `entityCellHtml({ avatar, name, sub, actions, title })`.
- **배지·상태·장르는 이름 뒤에 붙이지 않고 아래 줄**(`.cell-entity-sub`)에. 이름 길이가 달라도 배지 위치가 줄마다 같습니다.
- 듣기 ▶·비교 ⇄ 같은 버튼은 **칸 오른쪽 끝**(`.cell-entity-actions`)에 모읍니다.
- 이름·아래 줄은 한 줄 고정, 넘치면 **말줄임(…)**, 전체 이름은 `title`.

## 3. 칸 너비·행 높이

| 규칙 | 클래스 |
|---|---|
| 내용만큼만 쓰는 칸(순위·날짜·배지·버튼) | `col-fit` |
| 남는 폭을 다 쓰고 넘치면 한 줄 말줄임(근거·설명) | `td.col-clip` + `title` |
| 문장이 핵심인 칸(발굴 '주목 이유')은 **두 줄까지** 보이고 넘치면 말줄임 — 행 높이 48px 안에 들어감 | 칸 안에 `<span class="why-clamp">` + 칸에 `title`(전체 문장) — `css/ux.css` |
| 이름 칸 최소 폭 10em(약 140px) | `col-name` |
| 행 높이 최소 48px(사진 유무와 관계없이 같게) | 표 기본값. 촘촘 표는 `--row-h` 로 낮춤 |
| 표 안 배지·꼬리표는 글자 중간에서 줄바꿈 안 함 | 기본값 |
| 사진은 글자 기준선이 아니라 세로 가운데 | `.avatar { vertical-align: middle }` |

## 4. 목록(표가 아닌 줄)

- 알림 한 줄은 칸 위치를 고정한 격자: **[종류 112px] [별 64px] [사진·이름·▶ 최대 13em] [내용] [날짜(오른쪽)]**. ▶는 이름 바로 뒤에 두고(멀리 밀면 흩어져 보임), 이름 뒤에 ▶가 있든 없든 **내용이 같은 세로줄**에서 시작합니다.
- 같은 목록 안의 꼬리표는 같은 칸에, 날짜·숫자는 오른쪽 끝에.

## 5. 카드·격자

- 카드 격자 간격은 `--space-3`(12px) 또는 `--space-4`(16px) 둘 중 하나로, 한 격자 안에서는 같게.
- 카드 높이는 한 줄 안에서 같게(격자 `align-items: stretch`), 큰 숫자는 카드 위쪽 같은 높이에.
- 사진 크기는 표 28px · 목록 22~24px · 카드 40px · 팀 머리 72px 네 가지만.

## 6. 화면 폭

| 폭 | 표 |
|---|---|
| 1280·1920 | 그대로. 칸이 많은 표는 `.table-wrap` 안에서 가로 스크롤(페이지 전체는 가로로 넘치지 않음) |
| **375**(≤640px) | `stack-table` 표는 **쌓인 줄**(칸 이름은 `data-label`), 아니면 `.table-wrap` 가로 스크롤 |

## 7. 그림 규칙 (2026-11-28)

앱 안 모든 그림(관계망·씬 네트워크·공연장 흐름·Chart.js 막대·작은 HTML 막대)이 같은 말을 쓰게 하는 규칙입니다. 색 값은 `docs/app/css/graph.css` 맨 위 **그림 공통 토큰**(`--viz-*`), Chart.js 설정은 `docs/app/chart_theme.js` 한 곳에서 정합니다. 새 그림을 만들 때 색 값을 직접 쓰지 말고 토큰·함수를 씁니다.

**색은 의미로만 씁니다.**

| 역할 | 토큰 | 언제 |
|---|---|---|
| 주인공 | `--viz-focus` (주황) | 이 그림이 말하려는 것 — 점수, 후보, 이곳, 가장 최근 달, 늘어난 값 |
| 비교 기준 | `--viz-compare` · `--viz-compare-2` (회색 두 단계) | 견줘 볼 대상 — '갈래 수만'·'공연 수만', 전체 출연 팀, 사건 전 |
| 중립 | `--viz-neutral` | 뜻 없는 한 계열(예: 지난달들) |
| 흐리게 | `--viz-weak` | 표본이 적어 믿기 어려운 값 |
| 기준선 | `--viz-ref` (점선) | 무작위 기대·기준선 |
| 신호 갈래 | `--viz-gig`(공연) · `--viz-sel`(선정·지원) · `--viz-rel` · `--viz-cur` | 갈래를 나눠 보일 때만 |

- 계열을 색으로 늘어놓지 않습니다(무지개 금지). 회색 배경 위에 주인공 하나가 기본입니다.
- 색 값은 dataviz 검사기로 맞췄습니다 — 밝은 화면 주인공 `#b4501f` · 비교 `#5e5d5c` · 비교2 `#929190`(색약 구분 ΔE 8.9, 보통 시력 15.9, 모두 바탕 대비 3:1 이상), 어두운 화면 `#f08a4b` · `#94928e` · `#5c5a57`(ΔE 9.9 · 15.8). 회색이 '색이 옅다' 검사에 걸리는 것은 일부러입니다(회색 = 비교라는 뜻). 어두운 화면의 가장 옅은 회색은 바탕 대비가 3:1에 못 미쳐, 그 그림엔 늘 아래 표가 같이 있어야 합니다.
- 밝은 화면에서는 **글자 강조색**(`--accent` `#a94b1c`)과 **그림 주인공 색**(`--viz-focus` `#b4501f`)이 조금 다릅니다 — 글자는 연한 바탕 위에서도 대비 4.5:1(Lighthouse color-contrast)을 넘어야 하고, 그림 색은 회색과의 구분(보통 시력 ΔE 15 이상)을 지켜야 해서입니다(2026-11-28).
- 어두운 테마는 같은 이름의 토큰이 다른 값으로 바뀝니다. Chart.js는 테마를 바꾸면 `applyChartDefaults()`가 토큰을 다시 읽습니다.

**축·잉크를 줄입니다.**

- 값 축은 **늘 0부터** 시작합니다(막대 길이 = 값). 눈금은 5개 안팎, 숫자에 단위(팀·%·건)를 붙입니다.
- 격자는 **값 축 한 방향만** 옅게(`--viz-grid`), 범주 축은 격자 없이 바닥선만. 축 테두리선은 그리지 않습니다.
- 숫자 눈금은 옅은 글자(`--viz-axis`, 11.5px), 범주 이름은 조금 진하게(`--viz-label`, 12px).
- 막대 끝은 4px 둥글게(바닥 쪽은 각지게), 묶음 막대 사이와 쌓인 칸 사이는 틈을 둡니다.
- 부분이 전체의 일부면(후보 ⊂ 출연 팀) 나란히 말고 **겹쳐** 그립니다(안쪽 좁은 막대 = 부분).

**범례·말풍선·이름표**

- 범례는 그림 **위 왼쪽**, 모양은 작은 둥근 네모. **계열이 1개면 범례 없음**(제목이 이름).
- 관계망·씬은 위 칩 줄이 범례 겸 필터입니다(누르면 숨김·강조).
- 말풍선은 표면색 + 얇은 테두리 + 둥근 모서리, 제목은 진하게, 값에는 단위.
- 기준선 이름은 선 끝에 바로 씁니다. 막대와 겹치면 그림 칸 오른쪽 밖에(`outside`).
- 숫자를 모든 막대에 붙이지 않습니다 — 강조할 것만, 나머지는 말풍선·아래 표.

**작은 HTML 막대(월별 공연·스파크라인)**: `docs/app/viz_bars.js` 하나로 그립니다(도시 페이지·도시 카드·공연장 목록 줄·카드).
- 막대 길이 = 값, **0인 달은 막대 없이 바닥선만**(작은 값을 최소 높이로 부풀리지 않음). 지난달들 = `--viz-neutral`, 가장 최근 달 = `--viz-focus`.
- 큰 그림(도시 페이지)은 왼쪽에 `0`·꼭대기 눈금(1·2·5 단위, 단위 붙임), 아래에 달 이름표(처음·끝·1월 — 붙으면 1월은 뺌). 작은 그림(카드·표 줄)은 눈금 없는 스파크라인.
- 말풍선(title)은 `2026-11 · 23일`처럼 단위를 붙입니다.
- 점 지도·지역 지도: 공연장 점·번진 색 = `--viz-focus`, 크기 모름 = `--viz-compare-2`, 시·도 면 색과 공연장 크기 점은 진하기 사다리(`--ramp-1~5`, 순서 있는 값). 크기 단추 줄이 범례 겸 필터(점과 같은 색 작은 둥근 네모).

**그림이 아니어도 되는 것**: 2×2 숫자(사건 전후)는 표가 맞습니다. 대신 칸 안에 작은 막대(그 줄 큰 값 = 100%)를 넣어 변화를 한눈에 보이게 합니다(전 = 회색, 후 = 늘었을 때만 주인공 색).

**점검**: 그림이 있는 화면은 `tests/e2e/routes.mjs`에 넣어 `bash scripts/e2e_check.sh`로 1280·1920·375 × 밝게·어둡게를 봅니다(씬 네트워크·공연장 흐름 탭·도시 확대 지도 포함, 120칸).
